# 小红书获客内容策略

更新时间：2026-06-12

## 目的

小红书内容不是泛 AI 教程，也不是单纯资源包。它服务于 DoodleStory 的产品验证：

> 用公开内容筛选正在做抖音图文、愿意提交方向或账号、愿意进入内容实验周期的人。

## 内容定位

不要讲：

- 我做了一个 AI 图文工具。
- 一键生成爆款图文。
- 免费资源包合集。
- 普通 AI 生图教程。

应该讲：

- 我用 N 条图文测试了几个方向。
- 哪些风格、标题、故事类型更容易出现正反馈。
- 为什么生成内容不是关键，下一条发什么才是关键。
- 一个账号内容实验应该如何记录数据。
- 图文账号为什么不能只靠感觉选题。

## 内容链路

实验数据 -> 可公开案例 -> 小红书选题 -> 视频脚本 -> 封面标题 -> 发布数据回填。

## 单条内容模板

```text
# 小红书脚本：{标题}

## 来源实验
- 实验周期：
- 测试账号：
- 测试内容数量：
- 核心发现：

## 开头
一句话打出结论。

## 正文结构
1. 我们测试了什么
2. 结果和预期哪里不一样
3. 为什么这个结果重要
4. 下一轮会怎么测

## CTA
如果你也在做抖音图文账号，可以发我你的方向，我帮你判断适不适合做一轮内容实验。
```

## 选题方向

1. 我用 30 条图文测试了 3 种风格，发现真正影响播放的不是画风。
2. 抖音图文账号第一轮不要追爆款，先追可解释的数据。
3. AI 图文工具不值钱，能决定下一条发什么才值钱。
4. 为什么同一个故事换画风后数据差很多。
5. 做图文矩阵前，先用 14 天验证这个方向值不值得继续。
6. 图文账号数据不好时，怎么判断是选题、画风、标题还是账号问题。
7. 如果你只会生成图文，不会复盘，AI 只是在帮你更快地制造垃圾。

## CTA 规则

公开内容只做筛选，不做低承诺引流。

推荐 CTA：

> 发我你的图文方向、账号数量和最近 3 条数据，我帮你判断是否适合做 14 天内容实验。

不推荐 CTA：

> 免费领取爆款资源包。

原因：资源包容易吸引收藏党和工具党，不一定有账号和发布动作。

## 咨询筛选问题

用户咨询后先问：

1. 你现在有几个抖音账号？
2. 过去 7 天发了多少条图文？
3. 最近 3 条播放、点赞、评论分别是多少？
4. 你想测试的内容方向是什么？
5. 你是否能连续 14 天发布？
6. 你是否愿意回传基础数据？

不满足账号、发布、数据回流的人，不进入实验包。

## 边界

- 不承诺爆款。
- 不公开客户未脱敏数据。
- 不用“复刻别人链接”作为公开主卖点。
- 不把小红书做成泛创业日记，必须围绕图文内容实验。
