## 停止条件

- 如果连续两轮同一方向无相对正反馈，停止该方向。
- 如果用户不发布或不回传数据，停止实验。
- 如果只有播放没有任何互动或转化迹象，下一轮优先检查选题和标题，而不是继续加功能。
