# YouTube 单频道拆解卡

这里集中保存从 LuluJAI 或官方 YouTube 研究中发现的频道逐个拆解。每个频道使用同一套字段，避免看到
某个高播放视频后临时改变口径。频道拆解只用于理解供给和包装，不是增长归因、脚本复刻或发布结论。

## 统一拆解模板

每张频道卡必须包含：

1. **身份与边界**：官方频道 URL / ID、发现来源、观察时间、当前公开视频窗口和缺失字段。
2. **逐条事实表**：视频 ID、标题、发布日期、时长、当前播放、直播状态、描述来源层级。
3. **题型结构**：每条的问题类别、历史具体性、现代对照和敏感风险。
4. **标题结构**：主体、问题 / 冲突、承诺、词数、模板集中度和语言缺陷。
5. **缩略图结构**：官方原图尺寸、文字、主体、构图、色彩、情绪与史实暗示风险。
6. **频道内分布**：总量、中位数、前 3 / 后 3、视频年龄和异常值；不以当前播放计算增长速度。
7. **来源包装**：描述中的直接来源链接、可识别引用、章节与泛化来源表述；不审计视频内事实。
8. **迁移判断**：分为可借鉴、不应复制、需要真实实验验证；单频道结果不升级 Skill 或策略记忆。
9. **下一对象**：只指定一个频道，使用同一字段继续，避免同时改变分析方法。

## 证据等级

| 等级 | 证据 | 允许的结论 |
| --- | --- | --- |
| `O1` 官方公开事实 | YouTube 官方视频页、oEmbed、RSS、官方缩略图 | 身份、标题、日期、时长、当前播放、公开包装 |
| `O2` 人工观察 | 标题和缩略图的统一分类 | 可描述模式与差异，不能归因表现 |
| `I1` 受限推断 | 频道内前后组对比、异常值与时间边界 | 只能提出待验证假设 |
| `X` 不可得 | CTR、留存、流量来源、发布时订阅、成本、收入 | 不补猜，不写成结论 |

## 复用边界

- 可以学习“问题如何收窄”“缩略图如何让机制可见”“来源如何公开”。
- 不复制频道名、固定标题、人物造型、缩略图构图、脚本、画面、音乐或素材。
- 播放高只能说明当前公开视频计数高，不能证明题材、标题或缩略图是原因。
- YouTube 视频不是史实来源；DoodleStory 候选必须另建机构资料、论文或一手材料来源账本。
- 缩略图只临时读取用于分析，不把第三方图片副本提交仓库。

两张新频道卡已经完成

对象更具体，但历史主体仍然通用。12/12 缩略图继续使用黄色字与同类兽皮卡通人，0/12 给出外部来源直链。

至少有学术 / 机构来源；但 0/12 标题点名文明、地点、遗址或时期，猛犸尸体住房也暴露了视觉证据错位。
