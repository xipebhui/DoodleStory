## 结论先行

它确实提供了前五张频道卡缺少的**标题具体性**：0/12 使用 `Human(s)` 通用主体，11/12 点名 Rome、
Sparta、Persia、Mongols、Julius Caesar、Homer / Odysseus 或具体历史群体。5/12 使用 `10 Things / Ways`

等“回到记录”的可信度承诺。标题不再把所有历史压成无地点的古人类，这是可迁移的结构差异。

但具体性几乎和暴力承诺绑定：既有统一分类为 10/12 战争 / 惩罚、1/12文学 / 文明、1/12 冬季物流；
标题连续使用 prisons、death、avenge、killed、brutal、punished、darker、crucified、betrayed、feared

大白字、红箭头和环境场景。可迁移的是“具体主体 + 明确后果”，不是暴力升级或写实受害画面。

来源包装表面稳定但可审计性不足：12/12 有章节和 `SOURCES & FURTHER READING`，每条列出 4–7 位古代

本卡满足横向审计的停止条件：Buried Empires 的新信息主要是“具体文明 / 人物 + 长篇章节”，其视觉
增量主要依赖暴力，来源没有直链，唯一较非暴力的罗马冬季题又重复了已知严寒簇。**停止剩余频道卡，
不再追加 Explain In Paint 或机械补齐名单；下一步转入 Paynes Creek 单条本地样片的视觉来源与授权

## 标题系统

### 具体性与承诺结构

- 0/12 直接使用 `Human(s)`，11/12 有明确文明、人物、人群或地点；唯一 `G` 是跨文明的古代监狱清单。
- 5/12 是数字清单；7/12 是 `What / Why` 开头的解释或结局问题。
- 4/12 使用 `really / actually / recorded by history`，把“流行版本可能错了”作为可信度与好奇心入口。
- Sparta 出现 3/12，Rome / Roman 出现 4/12；其余分别锚定 Persia、Caesar、Ancient Greece、Homer /
  Odysseus、Mongols、German Forest 与 Via Appia。
- 10/12 属于战争、惩罚或政治暴力；文学重读和冬季后勤仍被 `darker`、`killed entire armies` 包装。
- 12/12 都依赖负面后果词，形成 death、revenge、punishment、betrayal、fear、darkness 的一致情绪场。

和前五频道相比，主体边界明显进步：观众能知道“哪个文明 / 哪组人 / 哪次事件”。但它没有证明具体性
本身产生播放，因为最高单条与另外两条 Sparta、另外四条清单和另外一条 `Worse Than Death` 同时存在
巨大差距。标题里的文明名、清单形式、暴力强度和视频年龄仍然纠缠。

### 两种长篇骨架

| 骨架 | 条数 | 结构 | 优点 | 风险 |
| --- | ---: | --- | --- | --- |
| 倒数清单 | 5 | 10 → 1；每项 1–3 分钟；结尾总结 | 容易持续制造新刺激，章节天然清晰 | 项目可互换、容易批量化；强度必须不断升级 |
| 单问题解释 | 7 | 场景钩子 → 背景 → 机制 / 人物链 → 后果 | 能围绕一个主体形成因果推进 | 仍大量依赖死亡、背叛、恐惧作为开场 |

DoodleStory 更适合迁移第二种的“一个主体 + 一条机制链”，不适合把 90–180 秒样片压成十项清单。

## 具体文明强对照的回答

### 确实带来的结构增量

1. **主体边界前置**：Rome、Sparta、Mongols、Caesar、Homer 直接进入标题，不把所有历史压成
   `Ancient Humans`。
2. **后果与主体绑定**：不是“古人如何生存”，而是“罗马军纪如何处理背叛”“森林如何破坏罗马军团
   优势”；这使机制有明确制度与环境边界。
3. **来源反差入口**：`What Homer Actually Wrote`、`What Really Happened` 等结构把流行印象与记录之间
   的差距变成问题，可用于有充分来源的纠错型选题。
4. **章节化因果链**：7–12 个章节不是简单时间戳，而是把背景、制度、执行与后果逐步展开。

### 不能脱离的主要混淆

1. 10/12 是战争 / 惩罚，另外两条标题仍使用 `darker` 与 `killed`；具体性没有在非暴力题库中独立出现。
2. 写实伤害画面、负面词、文明名、24 分钟长叙事与异常播放同时变化，没有单变量对照。
3. 最高视频是单条异常，另外两条 Sparta、另外四条清单和相似死亡短语都是强反例。
4. 来源栏稳定但没有直链或定位；“具体文明”没有自动转化为更可审计的事实流程。
5. 非暴力冬季后勤只是已知严寒簇的罗马版本，没有补出新的问题类别或视觉机制。

结论：Buried Empires 证明**具体文明标题是可执行的供给结构**，没有证明它能脱离暴力取得表现，也没有
提供 DoodleStory 尚未掌握的新制作机制。Paynes Creek 已经能直接使用“古典期玛雅 + 伯利兹南部 + 盐
厨房 / 独木舟”完成同样的主体边界，而且不需要酷刑、尸体或战争作为点击前提。

## 可借鉴、不应复制、待验证

### 可借鉴的设计机制

1. 标题前置一个文明、人物、地点或制度主体，再用一个具体后果形成问题。
2. 用“流行说法 vs 一手 / 考古记录”的差异做叙事入口，但必须真的展示来源边界。
3. 章节标题承担论证推进：限制 → 制度 / 工程 → 执行 → 后果，而不是十个可互换刺激点。
4. 环境约束必须和具体组织能力连接，例如森林破坏军团编队、冬季后勤依赖营地与补给。

### 不应复制的模式

1. 不复制 `brutal / worse than death / darker / killed` 的连续强度升级和十项暴力清单。
2. 不使用近距离刑具、惊恐受害者、被绑人物、十字架阵列或来源未映射的处刑场面作为默认缩略图。
3. 不把写实合成感当成历史准确，不凭盔甲、旗帜和电影光线替代视觉来源清单。
4. 不用作者名单替代直链、版本、页码 / 章节和主张映射。
5. 不把 24 分钟、多章节与一条异常播放直接迁移到 90–180 秒首轮样片。

### 公开数据无法回答

1. 具体文明名是否提高搜索匹配或 CTR，还是仅与暴力承诺、频道阶段和外部推荐共同出现。
2. 无字写实伤害图与早期大字解释图，哪一种改善了点击后的观看质量。
3. 章节化 24 分钟内容的留存峰谷，以及观众是否因来源、故事或刺激画面继续观看。
4. 来源名称是否被观众使用，缺少直链对审核返工和可信度有什么影响。
5. 同样具体但非暴力的历史机制题，在这个频道是否能形成可复现分布。

这些问题只能由同一频道、同一视觉与时长条件下的真实发布实验回答，市场公开视频不进入
`strategy_memory.md`，也不修改 Skill。

## 对 DoodleStory 的合理设计

Buried Empires 的有效增量可以压缩成一句：**不要只讲“古人”，要讲某个具体系统在某个限制下如何
运作。** 对 Paynes Creek 可转换为：

```text
不使用：How Did Ancient Humans Get Salt?
可研究：How Maya Salt Makers Turned Coastal Brine Into Salt for the Inland World

不使用：受刑者惊恐脸 + 红色刑具
可研究：陶盆架在火上、盐晶形成、船桨与泻湖水路；只画来源支持的机制物件

不使用：十项越来越残酷的清单
可研究：内陆需要 → 海岸生产 → 浓缩 / 煮卤 → 可运输形态 → 水路证据 → 未知路线
```

这不是最终英文标题或脚本。正式样片前还要建立服饰、陶器、木构、独木舟、地图和考古现场的视觉来源
与授权清单，并在非写实解释性插画中标明哪些是直接证据、哪些是重建。
