## 标题系统

### 两条稳定轴线

1. **古代限制轴**：灾后重建、弱小人类、航海、冰河期、牙科。
2. **现代镜像轴**：现代食物、现在仍怕黑、谁更聪明、身体与现代环境错配、古 DNA、现代人石器时代。

两轴都用问题包装，但现代镜像不只是措辞：6 条标题直接出现 `modern / us / you / still / no longer`
或把现代人放入石器时代。它把“古代知识”转成“这和我有什么关系”，比纯古人类问句多一个当代入口。

### 可以确认的标题特点

- 9/12 直接含 `Human(s)`；6/12 是明确现代对照；标题都只有一个核心问题。
- 9/12 使用问号；另外 3 条使用断言或反驳，包括 `ALL GONE` 对应的灾后思想实验与古代外星人纠偏。
- 强化词较克制，常用 `still`、`wrong`、`nothing`、`probably`，比 `darkest / deadliest` 更偏解释与反差。
- 只有 Ice Age、Stone Age 和个别描述给出时期边界；标题仍以通用人类主体为主。

### 标题与实际承诺的偏移

- “古人会怎么看现代食物”描述开头实际讨论自助餐过量与现代意志力，是演化心理 / 饮食错配，而不是
  可验证的古人观点；标题使用拟人化假设扩大了事实范围。
- “人类仍怕黑”更接近现代心理解释，缩略图没有古代场景；它会稀释历史频道定位。
- “古代牙科更糟”标题很强，但跨越多个时期和遗址，需要描述中的证据边界才能避免宽泛归纳。
- `Probably Wrong` 为纠偏留出概率空间，比绝对否定更稳健，但缩略图 `NOT ALIENS` 又变成绝对断言。

Pastly 的现代对照不是偶发一张图，而是 6 张重复使用的视觉结构。它的识别锚点主要是黄色大字和大眼

如果 DoodleStory 借鉴，应固定“对照构图变量”，不要同时更换人物画风、字体和细节密度。

## 描述与来源包装

Pastly 已形成比标题更稳定的描述模板：

- 12/12 有 `Sources` 或 `Sources and further reading` 标题；
- 8/12 有章节时间戳；
- 5/12 明确写出虚构场景、简化类比、谨慎解释、证据不完整或无法完全证明；
- 2/12 给出可直接打开的外部来源链接：Ancient Aliens 有 11 个，现代人石器时代有 1 个；
- 其余描述里的 URL 主要是频道自身视频和主页，不能把 `url_count` 误当成外部来源数。

优点是读者总能看到来源区与边界声明；缺点是大多数引用只有作者 / 机构 / 论文名，仍需人工搜索才能
核验。DoodleStory 应保留它的固定栏位和不确定性声明，同时把核心主张直接链接到来源，避免“列了来源
标题但不能点开”的半可审计状态。

## 可借鉴、不应复制、待验证

### 可借鉴的设计机制

1. **现代镜像入口**：不是只问古人怎么做，而是让现代人看到自己身体、手机、食物和恐惧与过去的关系。
2. **古今分屏**：同一画面并列两个世界，能让抽象演化错配变成可见冲突。
3. **固定来源与边界栏**：12/12 有来源区，部分视频明确虚构、简化与证据不完整，适合事实内容流程。
4. **标题与缩略图分工**：标题给完整问题，缩略图压成 `WRONG WORLD / STILL IN YOU / SURVIVE?`。

### 不应复制的模式

1. **把假设写成古人观点**：无法验证“古人会怎么看现代食物”，应改为可研究的身体机制或考古证据。
2. **来源名称替代直链**：有 `Sources` 标题不等于可快速审计；核心主张必须能回到原来源。
3. **同时更换画风**：手绘、纸张草图、半写实暗房和卡通分屏混用，会让包装变量与风格变量混在一起。
4. **缩略图绝对化**：标题写 `probably wrong`，图却写 `NOT ALIENS`；视觉不能比证据更绝对。
5. **把现代对照数据写成因果**：6 条组内仍混有年龄、题材、时长和视觉差异，不能据当前均值批量复制。

### 需要真实实验验证的假设

1. 固定题型、时长与画风后，古今分屏是否比纯古代场景提高 CTR 和 30 秒留存。
2. 同一来源账本下，“这和今天的你有关”是否比“古人怎么做”提高收藏、评论或长尾观看。
3. 明确不确定性与直接来源链接是否提高信任，而不会削弱标题冲突。
4. 身体感知题（牙齿、饥饿、寒冷）是否比宽泛演化题更容易形成单一视觉机制。

这些都是未来单变量实验候选，不进入 `strategy_memory.md`，也不修改 Skill。

## 对 DoodleStory 的合理设计

Pastly 最适合迁移的是“古代机制解释现代感受”，但必须把无法验证的古人心理改写为证据支持的问题。
映射到 Paynes Creek 盐候选，可以设计两个不同包装变量，留给下一轮正式比较：

```text
A：纯历史机制
公元 600–900 年的玛雅海岸盐工，如何把卤水变成可运输的盐？

B：现代对照入口
没有盐矿、工厂和卡车时，一座玛雅内陆城市如何得到每天需要的盐？
```

两者使用同一来源账本、相同视频长度、相同视觉风格与相同生产—运输链；只改变标题 / 首图的现代便利
参照。这里还不是最终标题、缩略图或发布实验，不把组内公开播放差异提前写成预期结果。

## 当前决策

决策：**Pastly 保留为“现代镜像 + 古今分屏 + 来源边界栏”的包装参照，不作为现代对照已获验证的证据。**

- 允许：借鉴现代便利缺失、古今分屏、来源栏和不确定性声明。
- 禁止：复制频道标题、人物造型、具体缩略图、假想古人观点或绝对化视觉结论。
- 证据等级：官方事实 `O1`、标题 / 视觉结构 `O2`、现代组表现差异仅 `I1`。
- 规则状态：不更新六题排序、默认视频长度、`strategy_memory.md` 或 Skill。

下一步只比较本卡与 [Oddlyhuman 频道卡](oddlyhuman.md)，判断纯历史机制与现代镜像是否能收敛成一个
可执行的单变量包装实验；不进入 Venn Stories，也不继续翻 LuluJAI。
