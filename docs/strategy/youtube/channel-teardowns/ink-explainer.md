## 结论先行

[Ink Explainer](https://www.youtube.com/@Inkexplainer96) 当前最近 12 条覆盖 2026-04-28 至 08-07，跨度
101 天，平均 / 中位发布间隔 9.2 / 9.3 天。11 个间隔中有 7 个集中在 8.9–10.1 天，另有两个约 13 天、
一个约 5 天、一个约 3.8 天；它是目前五张频道卡里节奏最接近稳定“九天一条”的窗口，但公开日期不能
证明团队产能、成本或未来排期。

LuluJAI 多次命中不是同一单条反复出现造成的错觉。连续降雨 1,228,405 播放、排窗口第 1，占 27.6%；
环球旅行 675,621、排第 4，占 15.2%；两个锚点合计占 42.8%。更重要的是，从 05-11 的时间感知到 07-16
的严寒，连续 8 条当前都超过 137,000 播放。窗口总计 4,444,616、中位数 193,112；去掉最高降雨后，
其余 11 条中位数仍为 188,941。因此它比“一条异常 + 长尾”更接近**一段连续高位带**，但最新两条和
最早两条仍明显低，不能把这段公开计数写成已经稳定的频道基线。

历史具体性依旧没有进入标题。9/12 标题直接使用 `Human(s)`，3/12 使用枪、娱乐性大麻、酒精等具体
技术 / 物质，冬季和连续降雨提供两个环境限制；0/12 点名文明、地点、遗址或时期。与 ThinkMan 相似，
对象和情境容易理解，历史主体仍被压成通用人类。真正的地点、年代、论文和遗址大量存在于描述中，说明
频道采用“宽标题吸引 + 描述补具体性”，而不是让标题本身承担可核对边界。

来源包装是明显增量：11/12 有研究 / 来源块，最近 9 条连续提供外部链接，8/12 至少有一个 DOI、学术
出版物、机构或研究仓库链接；3/12 有章节。最早三条没有可用直链，其中疾病视频甚至保留了疑似失效的
链接占位文本；枪械视频虽然有 11 个来源链接，却主要指向 Wikipedia，另有 1 个赞助链接。来源流程已经
从“列研究者”升级为“可点击”，但链接数量仍不等于每条主张都被直接支持。

视觉没有单一模板：12/12 是 1280×720、都有大字和黑轮廓插画，但只有 6/12 使用黄色字，人物精细度、
色彩和场景在兽皮火堆、动物、现代海滩与粉色扁平图之间变化。两个锚点分别用洞穴避雨和沙漠迁徙，能够
一眼看懂情境；严寒图却把人画在完整猛犸尸体内部取暖，而描述来源讨论的是猛犸骨结构，存在严重机制
错位。可借鉴的是“让限制场景可见”，不是复制猎奇尸体、通用兽皮人或文字模板。

## 标题系统

### 模板与具体性

- 11/12 使用疑问结构，只有严寒是 `The Disturbing Ways...` 陈述式；8/12 实际包含问号。
- 9/12 标题出现 `Human(s)`，另 3 条分别是动物行为、时间感知和 IKEA 效应。
- 3/12 点明具体技术 / 物质：枪、娱乐性大麻、酒精；2/12 点明环境限制：冬季、连续降雨。
- 0/12 点名文明、地点、遗址、具体时期或年代；`the World` 和 `Ancient / Early Humans` 仍是宽主体。
- 至少 4 条有明显英语或格式问题：`How Did Human ... Invented`、`Humans Started Smoking`、
  `Why Life Speeds Up`、`what is The IKEA Effect.`；另有大小写和标点不一致。

标题把“地点 / 论文级细节”全部留在描述。例如枪械描述具体写到中国炼丹、德安之战、黑龙江手铳和
君士坦丁堡，严寒描述写到 Denisova、Mezhyrich、Sibudu 与年代，酒精描述写到 Raqefet、Göbekli Tepe、
贾湖和埃及；标题仍只写 `Human(s)`。这提高了入口普适性，也增加了标题承诺过宽和跨时代拼接的风险。

| 历史具体性 | 枪械有东亚建筑 / 战场暗示，物种有多类人属对比；其余古代画面多为通用洞穴、沙漠和兽皮人物 |

### 12 条缩略图文字

`BORN TO KILL?`、`FIRST GUN?`、`COZY INSIDE?`、`RAINED ALL WEEK`、`TRAVEL HOW?`、`Why Us?`、
`STONED ALL DAY`、`Do They Know It's a BABY?`、`DRINKS ALL DAY`、`WHY TIME FEELS FASTER NOW?`、
`‘I WILL DIE’`、`THE IKEA EFFECT ?`。

视觉优势是场景化：降雨不是只画雨滴，而是把洞外暴雨与洞内火堆并置；旅行让背负婴儿、食物和容器
进入画面；物种题用多类人属并排表达竞争 / 消失。主要风险包括：

1. 严寒图直接把三个人画在完整猛犸尸体胸腔内部烤火，公开描述和链接谈的是猛犸骨住房，并不能支持
   “住进新鲜尸体”；这是视觉猎奇替代机制的典型错位。
2. 捕食者图把带血石块嵌在人物头部并写 `BORN TO KILL?`，把演化解释压成暴力天性承诺；最新当前播放
   又很低，既不值得复制，也不能由结果反推暴力包装无效。
3. 大麻 `STONED ALL DAY` 与酒精 `DRINKS ALL DAY` 把历史 / 考古问题变成持续 intoxication 笑料，
   容易弱化健康、法律和文化差异边界。
4. 疾病图内嵌 `7:33`，与官方真实时长 8:03 不一致；稳定视觉仍需要缩略图元数据 QA。
5. IKEA 图改成粉色扁平人物、白底与黑字，动物图也使用另一套画法；频道有共同插画语言，但没有完全
   稳定的品牌模板。

## 描述与来源包装

来源流程呈现明确的时间演进：

- 11/12 有研究 / 来源块或研究列表；IKEA 是唯一没有来源块的一条。
- 最早三条 IKEA、疾病、时间感知都没有可点击外部来源；疾病保留机构名和失效占位字符，时间感知只列
  论文名称。
- 从酒精开始到最新捕食者，连续 9 条都有外部直链；其中 8/12 至少有 DOI、学术出版社、研究机构或
  文献仓库，枪械一条主要使用 Wikipedia。
- 枪械描述的 12 个外部链接中 1 个是赞助商，11 个是 Wikipedia；“有链接”与“来源等级足够”必须分开。
- 枪械、严寒、人类物种 3/12 有章节；章节没有随所有新视频稳定出现。
- 至少 5/12 使用 `possible`、`unknown`、`hypothesis` 或 `theory` 等边界词；其余描述仍有若干没有直链的
  精确数字或通用参考。

这套流程比 ThinkMan 的 0/12 外部直链更容易审计，但仍有三类缺口：核心开场数字只写“通用参考”；一组
链接没有逐句对应主张；二手百科被用来支撑长时间线。DoodleStory 应学习“每条视频公开来源”，同时保留
来源等级、主张映射和未知项，不把链接数量当成事实质量分数。

## 可借鉴、不应复制、待验证

### 可借鉴的设计机制

1. **把限制场景直接画出来**：洞外暴雨 / 洞内火堆、迁徙负重、物种并排都比单纯惊讶脸更能说明问题。
2. **宽入口与具体来源分层**：标题先让普通观众理解问题，描述再给地点、年代和论文；DoodleStory 需要
   进一步把一个具体锚点前置到标题或副标题。
3. **连续可点击来源流程**：最近 9 条都有直链，说明来源账本可以成为稳定发布步骤，而非偶发补充。
4. **规律但不高频的长视频节拍**：约九天一条为研究、来源审核、旁白和静态分镜保留时间；这只是流程
   参考，不是增长建议。

### 不应复制的模式

1. **猛犸尸体住房与暴力天性视觉**：不使用来源没有支持的剖面 / 尸体，不把演化解释包装成天生杀戮。
2. **通用兽皮人跨越全部历史**：描述有大量遗址和器物时，缩略图也应让一个真实机制物件可见。
3. **大麻 / 酒精全天 intoxication 笑料**：不以持续醉态替代历史、健康和法律边界。
4. **链接数量替代来源等级**：Wikipedia、赞助链接、论文 DOI、机构资料必须分层，不混成一个计数。
5. **文字与元数据 QA 缺失**：修复语法、大小写、问号、内嵌错误时长后才允许进入发布 Gate。

### 需要真实实验验证的假设

1. 在同一具体历史内容、账号和缩略图风格下，“生活限制场景”标题是否比抽象起源标题提高 CTR，同时
   保持 30 秒留存和平均观看比例。
2. 在同一限制题中，缩略图展示真实机制物件 / 动作是否比“人物在环境里等待”更能提高观看质量，而非
   只提高点击。
3. 标题加入一个地点或时期锚点是否牺牲泛点击，却改善搜索匹配、评论可信度和长尾观看。
4. 可点击主张—来源映射是否改善审核效率、返工率和观众信任；公开播放不能证明来源链接带来增长。
5. 约九天节拍与更高频节拍对制作质量和发布表现的影响；必须在同一账号、题型和生产条件下测试。

这些只保留为未来单变量候选。市场公开视频不是 DoodleStory 自有发布证据，不进入
`strategy_memory.md`，也不修改 Skill。

## 对 DoodleStory 的合理设计

Ink Explainer 最值得迁移的是“问题场景 + 可点击来源”，但需要再向具体历史收窄一步：

```text
宽问句：What Did Ancient Humans Do When It Rained All Week?
更可审计：某一有火塘、床铺或排水证据的遗址，如何应对连续湿冷？

宽画面：三个人在通用洞穴里等雨停
机制画面：遗址结构 / 火塘位置 / 排水路径 / 干燥燃料与食物保存，只画来源支持的部分
```

这一结构可以与已有六题来源账本结合：标题保留一个现代人能理解的限制，副标题或画面加入文明、时期、
地点和机制物件；描述按“主张 → 直接来源 → 证据等级 → 未知项”排列。若没有足够来源支持具体遗址，不用
猛犸尸体、神秘技术或通用古人类画面补足刺激。

## 当前决策

决策：**Ink Explainer 保留为“连续高位带 + 场景化限制 + 来源直链成熟”的重要参照；两个 LuluJAI
锚点都是真实高位，但榜单只覆盖了频道高位带的一部分，不能据此升级增长规则。**

- 允许：借鉴限制场景可视化、规律节拍、公开来源块和描述中的遗址 / 年代层级。
- 禁止：复制频道标题、人物造型、猛犸尸体、暴力 / intoxication 猎奇、无分层链接或错误时长。
- 证据等级：官方事实 `O1`、标题 / 视觉 / 来源结构 `O2`、连续高位带与包装关系仅 `I1`。
- 规则状态：不更新六题排序、默认视频长度、`strategy_memory.md`、Skill 或生产流程。

下一步不立即拆第六个频道。先把 **Oddlyhuman、Pastly、Venn Stories、ThinkMan、Ink Explainer** 五张
频道卡做一次横向审计，比较异常集中度、连续高位带、标题具体性、视觉机制和来源成熟度，再决定剩余六个
频道是否还有结构增量。
