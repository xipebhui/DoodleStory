# ThinkMan 当前窗口拆解

更新时间：2026-08-12 18:30（Asia/Shanghai）
状态：当前官方 RSS 12/12 条；盐种子与窗口第 10 条重合；研究观察，不是全频道抓取、增长因果或复刻方案

## 结论先行

[ThinkMan](https://www.youtube.com/@ThinkmanOrigins) 当前最近 12 条覆盖 2026-05-30 至 08-10，跨度 72 天，
平均发布间隔 6.5 天、中位间隔 4.0 天。07-03 以后 8 个间隔中有 7 个约为 4–5 天，另一个约 8 天，
说明频道近期已经从不规则试发收敛到接近每周两条；这仍只是当前窗口，不能外推长期排期或生产效率。

盐不是一条独占式异常。12 条当前播放合计 775,841、中位数 10,765.5；严寒 260,186（33.5%）、盐
222,859（28.7%）、糖 168,339（21.7%），前三条合计占 84.0%。最高单条占比明显低于 Oddlyhuman 和
Venn Stories，但频道仍不是均匀分布，而是**三个生存 / 资源问题共同主导**。更重要的是，同属日常限制的
铁、奶、石器时代求生三条合计只有 7,907；不能把前三条直接泛化成“所有资源题都有效”。

标题增加的是对象具体性，不是历史具体性。12/12 都是问题，10/12 直接出现 `Ancient Human(s)`，若加上
`Ancient Man` 则为 11/12；铁、奶、糖、盐 4/12 点明具体材料 / 食物，`Stone Age` 只有 1/12 点明宽泛时期，
0/12 点名文明、地点或遗址。因此 ThinkMan 比 Venn Stories 更容易看出“这一集讲什么东西”，但仍把跨地区、
跨时代历史压成一个通用古人类主体。

视觉也高度模板化：12/12 官方缩略图均为 1280×720、黄色文字配黑描边、同一黑轮廓细肢卡通古人类系统，文字
为 1–4 个词、中位数 2 个词。严寒、糖、盐三张的钩子分别是精确极端温度、巨型白色晶体和舌尖盐粒，
没有一个共同的机制物件结构；糖图甚至把史前甜味来源画成近似加工晶体，铁图把炼铁压成露天火堆烤石头。
它们适合制造瞬时理解，但不适合作为事实型历史画面的直接参照。

来源可审计性是当前最明显短板：0/12 有正式来源栏，0/12 有外部来源直链，只有关系题列出研究者姓名；
4/12 有章节，至少 7/12 使用 `probably`、`may have`、`possible` 或 `hypothesis` 一类不确定性语言。描述经常
提到考古、DNA、遗骸或研究证据，却不能从关键主张直接回查出处。可借鉴章节与边界语言，不应复制无链接的
“研究感”。

## 标题系统

### 模板集中度与具体性

- 12/12 是问题；4/12 使用 `When Did Ancient Humans First...`。
- 10/12 直接使用 `Ancient Human(s)`，加上 `Ancient Man` 后为 11/12；只有石器时代反事实未在标题中
  使用古人类 / 古代男人主体。
- 4/12 点明铁、奶、糖、盐等具体材料 / 食物；它们让对象更清楚，但主体和时间仍然跨越巨大范围。
- 1/12 出现宽泛时期 `Stone Age`；0/12 出现具体文明、地点、遗址或可核对年代。
- 3/12 有明显语法问题：`How Ancient Humans Survive...`、`What Ancient Human Used To Do...`、
  `Why Ancient Humans Babies Are Born...`。统一模板仍需要英语文字 QA。

ThinkMan 相对 Venn Stories 的增量是“资源名进入标题”，不是“历史问题被收窄”。例如糖视频描述跨越灵长类、
埃及、新几内亚、印度和工业生产，盐视频跨越自然钠源、罗马尼亚制盐、撒哈拉贸易、政府税制和现代饮食；
标题虽具体到一种物质，解释范围仍横跨数千至数十万年。

## 缩略图系统

### 统一视觉语法

| 维度 | 观察 |
| --- | --- |
| 画幅 | 12/12 为 1280×720、16:9 |
| 文字 | 12/12 使用黄色文字和黑描边；1–4 个词，中位数 2 个词；均位于上方 |
| 主体 | 12/12 为黑轮廓、细肢体、棕发 / 兽皮的卡通古人类系统；10/12 由同类白脸乱发男性主导 |
| 构图 | 一个反应人物或一组人物 + 一个问题物件 / 环境；大词占顶部约四分之一 |
| 色彩 | 草原橙黄与洞穴棕为主；严寒改成深蓝，关系题和仪式题使用黄 / 夜蓝色块 |
| 历史具体性 | 没有文明服饰、遗址、器物谱系或时期区分；同一人物承担数十万年人类历史 |

### 12 条缩略图文字

`DISCOVER IRON?`、`FIRST MILK?`、`JUST ONE CUT?`、`BEARD SURVIVED?`、`WHAT DID THEY SEE?`、
`FIRST SUGAR?`、`FIRST WAR?`、`-69°F?`、`1 IN 12?`、`FIRST SALT?`、`Worship?`、`SO WEAK?`。

优点是标题负责完整问题、缩略图负责瞬时钩子，手机端识别成本低。风险也很集中：

1. 糖图把人物画成抱着并舔舐巨型透明白色晶体，更像加工糖 / 盐晶体，而描述真正提到的是野生蜂蜜、
   甘蔗驯化和后来的结晶糖；视觉把漫长机制压成了错误时代感。
2. 铁图用棍子把石头直接伸进开放火堆，描述却强调木炭、原始炉和反复锻打；缩略图易把机制简化成
   “偶然烤石头”。
3. 严寒图使用精确的 `-69°F?`，关系题使用 `1 IN 12?`，但公开描述没有把数字映射到直接来源；精确数字
   增强点击承诺，也提高事实审核责任。
4. 盐图只有极小舌尖颗粒，没有呈现视频最有解释价值的盐源、制盐、运输或交易机制；对象明确但机制不可见。
5. 统一兽皮人设与 Venn、Oddlyhuman 等频道的通用古人类视觉接近，不是可直接迁移的品牌差异。

## 描述与来源包装

当前来源流程分成四个层次：

- 0/12 有独立 `Sources` / `References` 栏，0/12 有外部来源直链。
- 关系题写出 10 位研究者姓名，但没有论文、书名、年份、机构或链接；只能确认“来源包装”，不能快速审计。
- 铁、奶、关系、盐 4/12 有章节；盐的 12 章最完整，最新铁和奶也稳定为 5 章，说明章节正在形成流程。
- 至少 7/12 使用概率、可能、假说或争议措辞；但糖、盐等高播放视频仍把跨时代主张写得非常确定。
- 多条描述提到化石牙齿、岩画、DNA、牙菌斑、遗骸、Nataruk 或古代陶器，却没有建立“主张 → 来源”映射。

章节可改善导航，不能替代来源。DoodleStory 若研究同类材料题，至少应为关键地点、年代、数字和机制提供
可点击来源，并把直接证据、支持性解释和未知项分开；现有 Paynes Creek 盐来源账本已经比本频道公开描述
更接近该标准。

## 可借鉴、不应复制、待验证

### 可借鉴的设计机制

1. **把抽象史前史收束到一个熟悉物件**：铁、奶、糖、盐比“古代世界”更容易形成单集边界。
2. **完整问题 + 两词视觉钩子**：标题承担上下文，缩略图只保留对象或危险，不堆叠长句。
3. **章节化长视频**：最新铁、奶和盐把问题拆成机制阶段，适合来源账本和分镜一一对应。
4. **现代体验入口**：盐罐、喝奶、糖渴望、中央供暖等熟悉体验可以作为开头，不必把整集改成现代反事实。

### 不应复制的模式

1. **通用古人类替代历史主体**：不使用同一兽皮卡通人物跨越全部地域、文明和时代。
2. **无来源的精确数字与宽主张**：`-69°F`、`1 IN 12`、30 万年搜索、盐值黄金等承诺必须逐条回查。
3. **视觉机制错位**：不把糖画成巨型晶体，不把炼铁画成开放火堆烤石头，不用刺激画面替代真实过程。
4. **语法缺陷的批量模板**：标题和缩略图必须有独立英语 QA，不能因统一格式降低文字审核。
5. **把前三条当成赛道结论**：铁、奶、求生是同组反例，公开播放不允许升级“资源题有效”规则。

### 需要真实实验验证的假设

1. 在同一具体历史案例、时长和缩略图下，“现代熟悉物件的缺失”标题是否比纯历史机制标题提高 CTR，且
   不降低 30 秒留存和平均观看比例。
2. 在同一物质题中，标题加入文明 / 地点 / 年代是否降低泛人群点击，却提高搜索匹配、观看质量或评论可信度。
3. 缩略图展示真实机制物件（煮卤陶器、盐灶、运输工具）是否能替代巨型晶体和夸张表情，同时保持可读性。
4. 90–180 秒版本与 12–25 分钟版本在相同问题下的观看质量、制作成本和迭代速度如何；不能用跨频道公开播放比较。
5. `FIRST ...?` 与极端数字钩子是否只有点击优势，还是会因承诺过宽造成早期留存下滑；需要后台数据。

这些只保留为未来单变量候选。市场公开视频不是 DoodleStory 自有发布证据，不进入
`strategy_memory.md`，也不修改 Skill。

## 对 DoodleStory 的合理设计

ThinkMan 最有价值的启发是“物质可以成为历史机制入口”，而不是复制 `Ancient Humans + FIRST`。现有
Paynes Creek 盐研究可以直接展示更具体的替代方向：

```text
通用问句：When Did Ancient Humans First Start Eating Salt?
可研究方向：公元 600–900 年，Paynes Creek 盐工如何把海岸卤水变成可运往内陆的盐？

通用画面：洞穴里有人舔舌尖盐粒
可研究画面：盐厨房木构 → 煮卤陶器 → 盐饼假说 → 船桨与沿海—内陆交换边界
```

这样仍保留“人人都需要盐”的普遍入口，但正文只回答一个地区、时期和证据链。标题不承诺解释 30 万年
人类史，缩略图不使用本频道的人物、字体或构图，来源账本逐项标记直接证据、支持性解释与未知项。

但严寒、盐、糖三条形成高集中候选簇，仍不能升级为规则。**
