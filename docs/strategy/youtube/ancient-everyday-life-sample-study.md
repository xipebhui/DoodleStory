# YouTube 古代日常生活题型扩样

更新时间：2026-08-12
状态：公开视频市场样本研究；可进入后续单变量实验候选，不是增长结论或可发布脚本

## 结论先行

“古代日常生活中的具体限制”已不再只是单条观察。首轮保留 **9 条严格样本，来自 9 个频道**；随后
LuluJAI 同一历史列表第 21–60 条又发现并经 YouTube 官方页面复核 Oddlyhuman 与 Pastly 两个新严格
频道，使当前候选池达到 **11 条代表视频、11 个频道**。首轮 9 个频道中有 5 个在 2026-08-12 的
公开订阅数不足 2 万；两个新增频道只保留 LuluJAI 发现快照，不把第三方订阅值当作当前官方值。

题型继续跨越身体与卫生、食物与盐、天气与庇护、军队卫生和育儿协作，不依赖单一女性健康话题。

因此，本轮允许把下面的包装机制提升为**后续实验候选**：

> 一个现代人熟悉的基本需要 + 当时缺少的现代便利 + 人类实际采用的解决机制。

这不是长期规则，也不证明该方向比现有六题更好。搜索样本有明显的标题模板聚集，尤其“古代人如何让
孩子活下来”在多个频道出现近乎相同的标题；没有频道后台留存、流量来源、制作成本和收入数据，也不能
判断播放来自题型、缩略图、频道历史受众还是推荐波次。

## 样本口径

### 发现来源

1. LuluJAI 会员长视频榜的 `英语 + 历史悬疑` 筛选，用于发现 Venn Stories、ThinkMan 和
   Ink Explainer 三条候选。
2. YouTube 公开搜索与关联视频，用于补充严冬、饮食、军队卫生和育儿协作样本。
3. YouTube Data API v3 的 `videos.list` 与 `channels.list`，用于在 2026-08-12 复核标题、频道、
   发布时间、时长、播放、点赞、评论、订阅和频道视频数。

这是带明确问题的方便抽样，不是随机样本。YouTube 搜索和 LuluJAI 榜单排序都会受时间、地区、采集与
产品排序影响，不能用 11 条样本估算整个历史赛道的占比或成功率。

### 严格保留条件

- 标题围绕一个具体、可感知的日常限制，而不是宽泛的王朝史、战争史或“古人一天做什么”。
- 核心承诺是解释某种解决机制，而不只是罗列猎奇事实或营造“过去很可怕”。
- 内容对象属于史前、古代或前现代日常生活，且按事实内容包装。
- 排除真实犯罪、当代政治、科幻、受版权保护 IP、现代教程和仅因标题包含 `ancient / history` 被误分的内容。
- 视频公开可访问，且官方公开接口能复核身份和基础数据。

YouTube 视频在这里仅用于研究题型和包装，不作为历史事实来源。任何后续选题仍需单独建立机构资料、
同行评议研究或一手材料组成的来源账本。

## 可以确认的重复信号

### 1. 不是单一敏感题材

当前 11 条样本仍可分为四组：

- 身体与卫生：经期、军队排泄；
- 必需资源：盐、食物；
- 天气与庇护：连续降雨、严冬；
- 家庭与群体协作：儿童存活、婴儿安抚。

共同点不是“恶心”或“危险”，而是把现代默认便利拿掉后，追问一个具体的人类需要如何被满足。这比
“古代人的一天”“古埃及日常生活”一类宽泛综述更容易形成单一标题承诺和可画因果链。

### 2. 低订阅频道中也出现公开异常样本

Venn Stories、ThinkMan、Buried Empires、Basically Primitive 和 History Alive Animated 的观察时
订阅数都不足 2 万，而对应视频分别有约 11.7 万至 64.8 万播放。由于订阅数已包含视频发布后的增长，
这只能确认“候选不限于成熟大频道”，不能计算发布时播放 / 订阅比，也不能证明新频道复制后会得到推荐。

### 3. 标题家族高度集中

多数标题使用 `How / What / When Did Ancient Humans...`，把限制直接放在问句里。育儿子类尤其集中：
同一搜索面同时出现多个频道使用 `How Did Ancient Humans Keep Kids Alive?` 或极近变体，发布时间也
集中在 2026 年 5–6 月。

这既是重复需求线索，也是模板化拥挤警告。后续不能复制固定句式；必须选择具体文明、时间、环境或
可验证机制，并让标题承诺与来源范围一致。

不是实时指标源。

## 仍然不能确认

- 没有展示量、CTR、30 秒留存、平均观看比例和流量来源，不能判断哪种限制真正驱动观看。
- 搜索词本身偏向 `ancient humans / survive / how did`，会放大相似标题，不能据此估算赛道规模。
- 三条育儿视频可能来自同一选题扩散或模仿波次；跨频道不等于独立创意机制。
- 经期、儿童健康与食物营养涉及敏感或健康主张，后续事实与表达审核成本高于城市基础设施题。
- 11 条都是 7:35–23:35 的普通长视频，中位时长仍为 11:37；样本面没有提供同机制短视频对照，不能据此
  把 DoodleStory 当前 90–180 秒默认研究假设改成长视频。
- 当前公开播放不等于获利、稳定增长或可复制制作利润。

## 当前决策

决策：**可进入后续单变量实验候选**，但不进入生产，也不升级长期规则。

推荐保留的候选结构是：

```text
具体日常限制
→ 缺失的现代便利
→ 2–4 个历史解决机制
→ 机制的代价、适用范围或未知项
```

首个“必需资源”来源账本已在 2026-08-12 完成，并把原问题收窄为：

> 古典期玛雅海岸盐工如何把 Paynes Creek 的卤水变成可运往内陆的盐？

候选比较、同行评议来源、事实 / 推断 / 未知分层和 research brief 见
[古典期玛雅 Paynes Creek 盐获取来源账本](ancient-salt-access-source-ledger.md)。它仍不是脚本或发布
实验；下一步只允许建立视觉来源与授权清单。现有六题排序、16:9 的 90–180 秒默认研究假设、
`strategy_memory.md` 和任何 Skill 规则保持不变。

## 11 个频道的供给结构复核

后续读取 11 个已验证频道的 YouTube 官方 RSS，共统一分类 129 个近期标题。两个由 LuluJAI 第 41–60 条
新增的频道虽然持续更新，但没有补出新的问题类别：Oddlyhuman 的 9/9、Pastly 的 9/12 标题直接使用
`Human(s)` 通用主体，内容仍落在既有日常限制、人类起源 / 演化或现代对照中。

129 条标题已经形成严寒、降雨、移动、酒 / 药物、工作、身体气味、捕食者、儿童 / 家庭和人类物种等
跨频道重复簇。新增频道只有 2/21 标题带明确地点或时期边界，没有缓解通用古人类模板拥挤。完整数据见
[LuluJAI 新增频道族同质性比较](lulujai-new-channel-family-comparison.md)。

因此，当前 11 个代表频道足够用于描述供给结构；不再扩大同类市场样本。下一步回到具体来源账本、视觉
授权或真实发布实验，不把“还能找到更多同类频道”误当作“还能发现新的内容机制”。
