# LuluJAI 新增频道族同质性比较

更新时间：2026-08-12  
状态：11 个 YouTube 官方频道 RSS 标题比较；题型层面达到停止条件

## 结论先行

LuluJAI 定向历史列表第 41–60 条新增的 Oddlyhuman 与 Pastly 是真实、持续更新的古人类解释频道，
但它们没有为当前研究补出新的问题类别或内容结构。11 个严格频道的 YouTube 官方 RSS 共提供 129 个
近期标题；统一分类后：

- Oddlyhuman 的 9/9、Pastly 的 9/12 标题直接使用 `Human(s) / Ancient Human(s)` 通用主体，分别为
  100% 与 75%，都超过预设的 60% 阈值；
- 两个新增频道的 21 条标题由 11 条日常限制机制、9 条宽泛人类起源 / 演化 / 行为和 1 条其他内容组成，
  没有战争 / 政治或明确文明史的新结构；
- 新增频道出现的严寒、火、酒、工作前生活、迁徙、食物、牙科、行为起源、物种与 DNA，在既有 9 个
  频道中都已有同类标题；没有一个“新问题类别”在两个新增频道中各出现至少 2 次；
- 新增频道只有 2/21 条标题带明确地点或时期边界，且其中 6/21 是现代对照或假设；它们没有提高当前
  样本的历史具体性；
- 129 条标题至少形成严寒、降雨、移动、酒 / 药物、工作、身体气味、捕食者、儿童 / 家庭和人类物种
  等九个跨频道重复簇。最强的不是“市场空白”，而是同一问句和题材正在被多个频道密集复用。

因此，本轮按预注册规则判定：

> **LuluJAI 会员榜在“古代日常限制有哪些频道和题型”这一研究问题上已经达到题型层面饱和。停止继续
> 翻页，也停止继续扩同类频道。**

这不表示榜单以后不会出现新频道，也不表示该题型没有市场；它只表示继续从同一宽分类寻找更多
`How Did Ancient Humans...` 标题，预计只能增加同质供给数量，不能提高当前 Agent 方向决策的质量。

## 预设停止规则复核

Sprint 合同在采集前定义：若两个新增频道近期标题均至少 60% 使用宽泛 `Ancient Humans / Humans`
主体，且没有一个新问题类别在至少 2 个频道各出现 2 次，则判定只增加同质供给。

| 检查 | Oddlyhuman | Pastly | 是否满足 |
| --- | ---: | ---: | --- |
| `Human(s)` 主体比例 | 9/9 = 100% | 9/12 = 75% | 两者均 ≥ 60% |
| 新增问题大类 | 0 | 0 | 没有新增 `D/E/W/C/O` 之外类别 |
| 新类在两个频道各 ≥ 2 条 | 不存在 | 不存在 | 满足停止条件 |

`D` 与 `E` 在两个新频道都很密集，但它们分别已在既有频道出现 43 条和 25 条，不是新增类别。迁徙、
严寒、酒、工作、身体与物种也都能回指至少一个既有跨频道簇。因此不能把“两个新频道都重复同一主题”
误写成“发现了新的主题”。

结论：**满足题型层面停止规则。**

## 对 DoodleStory 的最终影响

1. 保留“具体日常限制”作为后续真实实验候选，但不再从 LuluJAI 增加同类频道样本。11 个频道与
   129 个近期标题已经足以暴露主要题型和模板拥挤。
2. 标题竞争风险高于题材发现风险。后续若试验，必须把通用 `Ancient Humans` 改成具体文明、时期、
   地点与机制链，并建立独立来源账本；不能复制已经高频的问句。
3. 当前优先候选仍是已经完成来源账本的 Paynes Creek 盐生产—运输链，因为它比频道标题更具体、可核验，
   也能避开宽泛古人类模板。
4. RSS 标题只证明供给结构，不提供展示量、CTR、留存、流量来源、成本或收入。题型饱和不等于商业饱和，
   也不预测发布结果。
5. 不修改六题排序、16:9 的 90–180 秒研究假设、`strategy_memory.md`、Skill 或生产流程，不创建生成、
   发布、定时任务或自动接入。
