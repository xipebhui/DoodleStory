# Paynes Creek 样片视觉来源与授权清单

核查日期：2026-08-12

适用对象：古典期玛雅 Paynes Creek 盐生产—运输候选样片

状态：视觉 Gate **有条件通过**；不是法律意见、脚本、分镜或发布许可

## 结论先行

这条样片不需要依赖来路不明的历史图片即可制作。最稳妥的方案是：

- 用公共领域 Natural Earth 数据自行绘制区域底图；
- 用两篇 `CC BY 4.0` 的 Paynes Creek 原始研究核对木柱布局、陶器、漏斗和水下考古现场；
- 所有古代生产画面都独立画成非写实机制示意，不描摹论文构图；
- 如需加入“真实证据”插图，只从明确为 `CC BY 4.0`、且图注没有另列权利限制的论文图片中选择；
- 不直接使用 2005 PNAS 船桨照片、AIA / LSU 网页照片、`CC BY-NC-ND` 论文图片或搜索结果缩略图；
- 把原 `V6 市场交换` 改为抽象的“海岸到内陆”虚线网络，因为具体路线、市场建筑、买家和价格均未知。

因此，`V1、V3、V7` 可以进入原创视觉规格，`V2、V4、V5` 在保留“重建 / 可能”标记后可以进入，
`V6` 原设计不能进入，必须替换。人物只作为小比例劳动剪影，不做服饰特写。

## 一、判断规则

### 1. 权利状态

| 状态 | 本清单中的含义 |
| --- | --- |
| `reuse_allowed` | 当前来源明确允许预期的商业视频复用；制作时仍要保存许可快照并履行署名等条件 |
| `reference_only` | 可用于理解事实，但不复制、裁切、描摹、动画化或合成该来源的具体表达 |
| `permission_required` | 当前公开许可不覆盖商业或改编使用；直接使用前必须得到权利人书面许可 |
| `avoid` | 即使权利可能可用，也会造成年代、地域、身份或证据强度误导；当前样片不使用 |

### 2. 历史准确性与版权是两道独立 Gate

- 一张图来自考古论文，不代表它自动允许商用。
- 一张图是公共领域，不代表它能准确代表 Paynes Creek。
- 开放获取只说明可以阅读；必须继续看具体的 Creative Commons 许可证。
- `CC BY 4.0` 允许商业分享和改编，但需要合理署名、链接许可证并说明是否修改。
- `CC BY-NC-ND 4.0` 不允许商业使用，也不允许发布改编版本；对未来可能获利的 YouTube 频道按不可直接
  使用处理。
- 事实、方法和发现本身可以用于独立表达；论文照片、地图布局、线描和复原构图仍是受保护的具体表达。

规则入口：

- [Creative Commons：CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- [Creative Commons：CC BY-NC-ND 4.0](https://creativecommons.org/licenses/by-nc-nd/4.0/)
- [美国版权局：版权不保护事实、思想、系统或方法，但可保护具体表达](https://www.copyright.gov/help/faq/faq-protect.html)
- [PMC 版权说明：没有明确许可时应假定标准版权保护](https://pmc.ncbi.nlm.nih.gov/about/copyright/)

本清单采用保守的商业口径，不依赖“合理使用”作为默认素材方案。

### 整体 Gate

**有条件通过，允许进入“逐镜证据板与原创视觉规格”，但还不能进入生成或发布。**

通过原因：核心机制不依赖未授权图片；区域底图、生产装置、陶器组合与考古结尾都有可回查证据；

## 五、生产时的授权记录格式

每个实际进入视频的第三方图件都必须在制作目录保存一行记录：

```text
asset_id | creator | exact_title_or_figure | article_or_collection | source_url |
retrieved_at | license | license_url | changes_made | on_screen_credit | end_credit
```

`CC BY 4.0` 图件的最低署名要素：创作者、图号 / 作品名、论文名和 DOI、`CC BY 4.0` 链接，以及
“cropped / color adjusted / annotated”等实际修改说明。不得用统一的“图片来自网络”代替。

若只依据论文事实独立创作画面，也应在视频描述的“Sources”段映射到对应场景 / 主张，但不把原创图
错误标成论文作者提供。

## 六、制作前停止条件

- 画面必须出现具体市场、买家、价格、税收或已确认路线才能成立时，停止 V6，不补画。
- 必须直接使用 PNAS 船桨照片、AIA / LSU 项目照或 `CC BY-NC-ND` 图片时，先取得书面许可；没有许可
  就不进入样片。
- AI 生图若持续给出石砌宫殿盐厂、金属锅、王室羽冠、兽皮洞穴人或水下古代工人，停止生成并重写
  视觉约束，不挑“最像历史片”的错误图。
- 若要展示研究图件但无法记录确切图号、作者、许可和修改，删除该图件。
- 正式制作日期若距离本次核查较久，必须重新打开许可页面确认条款未变。
