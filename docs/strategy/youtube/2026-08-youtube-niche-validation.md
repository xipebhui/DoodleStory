# YouTube 赛道验证：适合 DoodleStory 的第一方向

更新时间：2026-08-02
状态：研究假设，尚未进入内容生产或发布

## 结论先行

建议首轮验证的方向是：**原创插画历史微纪录片 / 历史机制解释**。

不是做“AI 历史素材拼接”，也不是复制现有动画频道；而是用一个明确问题、可核验来源、原创
观点和自有画面语言，讲清一个历史中的人、制度、技术或日常选择为什么会改变后续结果。

建议的第一期边界：英文或全球受众可理解的叙事，默认采用 **16:9 普通视频**，单条 90–180 秒，
原创旁白，6–10 张有叙事作用的插画画面，清晰的来源账本和人工事实审核。这个时长只是首轮生产
假设；正式进入制作前需先用一条无发布成本的本地渲染确认当前视频模板的长度、字幕和画幅表现。

不能把 3:4 竖屏方案当作同一实验：2024-10-15 后上传的方形或竖屏、最长 3 分钟视频会被 YouTube
归为 Shorts，缩略图和分析指标都与普通视频不同。两种形态的详细分流见
[格式观察、平台分流与相邻赛道压力测试](format-and-adjacent-lane-review.md)。

这不是“历史赛道已被验证会成功”的结论。它是从当前产品的能力、公开的 YouTube 平台信号与
风险约束得出的**最值得先做小样本验证**的方向。

## 本轮假设与范围

### 工作假设

在“原创旁白 + 插画化解释”的生产形态下，历史中的具体因果问题（例如一个制度、技术或日常
选择为何出现）比抽象年表、新闻搬运或泛知识罗列更适合作为 DoodleStory 的首轮 YouTube 内容
机制。

### 明确假设

- 目标受众尚未指定国家与语言。本报告暂以英文 / 全球受众可理解的内容为比较基准，不能据此
  推出英文市场必然更优。
- 首批实验只允许一个原始语言。YouTube 支持翻译元数据、自动配音和受限开放的多语言音轨，但当前
  DoodleStory 发布请求未包含相关字段；详细边界见
  [多语言与获利路径边界](language-and-monetization-boundaries.md)。
- 本轮不调用 DoodleStory 的频道研究 Tool、模型、媒体 Tool 或发布接口；下列频道只是后续可
  用 `inspect_youtube_channel` 深挖的观察对象。
- 平台公开报告反映广义内容信号，不能代替对某一细分赛道、语种、频道基线或题目的实测。

## 平台公开证据：能说明什么，不能说明什么

| 公开证据 | 能支持的判断 | 不能支持的判断 |
| --- | --- | --- |
| YouTube 表示，2024 年一个 300 个虚拟创作者的样本在视频、直播和 Shorts 中获得超过 150 亿观看；报告同时强调虚拟创作背后仍需人的真实连接。([YouTube Blog](https://blog.youtube/culture-and-trends/youtube-culture-trends-report-virtual-creators/)) | 非真人、数字化表达本身不是障碍；频道仍需要辨识度与创作者观点。 | 不能证明任何 AI 图片频道都会获得流量。 |
| YouTube 的独立动画报告称，受访的 14–24 岁动画粉丝中，61% 表示愿意看 YouTube 独立动画，63% 每周至少观看一次。([YouTube Blog](https://blog.youtube/culture-and-trends/independent-animation-trends-report/)) | 插画 / 动画化叙事有现实的受众基础，也具有跨语言潜力。 | 这不是历史赛道的直接观看量，也不等同于低成本静态分镜可与成熟动画制作竞争。 |
| YouTube 在教育使用研究中发现，受访年轻人中 74% 会用 YouTube 学习学校的新内容。([YouTube Blog](https://blog.youtube/news-and-events/eu-youtube-for-education-study-2025/)) | “解释清楚一个问题”的教育性价值值得保留，不能只依赖视觉刺激。 | 该研究不等同于成人历史内容的商业或增长预测。 |
| YouTube 说明，频道的重复、批量化或缺少原创叙事 / 教育价值的内容不具备获利资格；通用 AI 模板尤其可能被判为非真实内容。([YouTube Help](https://support.google.com/youtube/answer/1311392?hl=en-AU)) | 必须把原创研究、观点、叙事差异和人工审核设计为流程硬约束。 | 不能通过“换模型、换配音或换几张图”消除重复内容风险。 |
| 对逼真 AI 生成或明显改造的内容，YouTube 要求在适用时进行披露；披露本身不会限制受众或获利资格。([YouTube Help](https://support.google.com/youtube/answer/14328491?hl=en-PG)) | 发布前需要一项 AI 合成内容判断 / 披露 Gate。 | 不能忽略事实、版权、隐私和误导性表达的其他责任。 |

补充背景：YouTube 2025 年的文化报告写到，平台每日观看时长超过 10 亿小时；这只能说明平台的
内容规模和全球性，不能作为赛道需求的替代指标。([YouTube Blog](https://blog.youtube/culture-and-trends/trends-report-20th/))

## 赛道比较：以当前系统适配度筛选

评分为产品适配判断（5 高、1 低），不是外部市场份额或收入预测。

| 候选方向 | 静态插画 + 旁白适配 | 原创 / 来源可控 | 当前研究 Tool 利用 | 平台 / 合规风险 | 首轮建议 | 判断 |
| --- | ---: | ---: | ---: | ---: | --- | --- |
| 历史微纪录片 / 历史机制解释 | 5 | 4 | 5 | 4 | 首选 | 事件、人物、制度和日常生活都可拆成静态因果场景；可使用多源公开史料并写来源账本。 |
| 世界神话与民间故事的原创解释 | 5 | 4 | 4 | 4 | 备选 A | 高度可视化，且许多母题可从公版或可靠译本研究；必须避免照读受版权保护的现代改编。 |
| 地理 / 城市 / 日常文化机制解释 | 4 | 4 | 5 | 3 | 备选 B | 适合“为什么会这样”的问题，但地图、数据图与当代地缘话题对视觉和事实核验要求更高。 |
| 科学史 / 太空“假如”解释 | 4 | 3 | 4 | 3 | 后续 | 画面空间大，但科学准确性、图表与专业审校门槛更高；不宜作为无专家流程的第一条赛道。 |
| 原创情感 / 道德故事 | 5 | 5 | 2 | 2 | 暂缓 | 制作最容易，但很容易落入可互换模板和重复叙事风险，且当前 YouTube 政策对此更敏感。 |
| 新闻、金融 / 医疗建议、名人八卦、真实犯罪、儿童向 | 2–4 | 1–3 | 3 | 1–2 | 不选 | 分别存在时效、专业责任、隐私 / 暴力、儿童合规或版权风险；也通常需要真人、实拍、图表或更强编辑能力。 |

### 为什么不是先做“完全动画剧集”

独立动画是一个积极信号，但当前 DoodleStory 的主能力是**有旁白的静态分镜视频**，不是角色动画、
连续镜头运动、音乐剧或粉丝共创 IP。第一阶段应把优势放在“解释和叙事清晰”，而不是承诺与成熟
动画工作室比帧率或角色表演。

## 首选方向的产品定义

### 内容承诺

> 用一个反直觉的问题，讲清一段历史中人们在什么限制下做了什么选择，以及这个选择后来造成了什么。

每条应具备：

1. **一个可验证的中心问题**：不是“古罗马历史”，而是“为什么某种制度在当时有用、后来却造成问题”。
2. **一个明确论点**：脚本应能用一句话说出自己的解释，而不是按时间线念资料。
3. **至少两类独立来源**：例如博物馆 / 大学 / 学术出版物 / 可靠史料库；频道研究结果只能当格式参考。
4. **画面承担解释任务**：人物位置、工具、制度关系或后果要可见，不能只是漂亮背景轮播。
5. **尾部的当代连接或可讨论问题**：不制造虚假类比，不替观众下结论。

### 适合的首批题目形态

以下是题目结构，不是可直接发布的事实结论；进入写作前均要建立来源账本并人工核验。

| 题目形态 | 示例标题方向 | 视觉优势 | 主要风险 |
| --- | --- | --- | --- |
| 日常生活背后的制度 | “Why did ancient cities ration water this way?” | 水、城市、器具、排队和阶层关系均可画。 | 不同文明不能混用制度；需限定时间和地点。 |
| 技术如何改写选择 | “The small tool that changed how an empire moved food” | 工具、运输、路线与结果构成清晰分镜。 | 容易把多因果历史简化成单一发明神话。 |
| 决策时刻的代价 | “The choice that solved one crisis — and created the next” | 决策者、约束、即时收益与长期后果可对照。 | 不能把争议史学判断写成唯一事实。 |
| 被忽略的人与系统 | “Who actually kept this ancient system running?” | 从宏大叙事落到劳动、家庭和现场细节。 | 史料不足时必须承认不确定性，不能补写细节。 |

### 格式观察对象（不是复刻对象）

后续进入研究 Sprint 时，可用项目已有的频道研究 Tool 对下列频道逐项观察标题结构、时长、描述、
评论问题、封面信息密度与近作变化，但不得复制具体脚本或画面：

- [Simple History](https://www.youtube.com/@simplehistory)：观察“一个历史问题 → 图解场景 → 解释”的压缩方式。
- [History Matters](https://www.youtube.com/@HistMattersYT)：观察短时长、单问题、带观点的历史解释节奏。
- [Mythology & Fiction Explained](https://www.youtube.com/@mythologyfictionexplained)：观察神话 / 世界观解释如何组织信息；用于备选赛道对比。
- [RealLifeLore](https://www.youtube.com/@reallifelore)：只作为地理解释的对照，提醒我们地图和当代事实核验是额外制作能力，不是当前首轮默认能力。

本轮公开格式观察已完成第一批人工研究卡：History Matters 主要用于观察“单一 `Why / When` 问题”的
包装一致性，The Armchair Historian 用于观察描述区来源和团队署名，Simple History 用于提醒我们不要在
首批实验中同时混用比较、榜单、传记和因果问答。公开页没有频道后台数据，因此不能据此判断哪种格式
表现更好；完整观察与相邻赛道压力测试见
[format-and-adjacent-lane-review.md](format-and-adjacent-lane-review.md)。

六个已完成双来源初查的候选覆盖：罗马港口粮食供应、印加道路通信、罗马城市供水、江户消防、吴哥
水网和摩亨佐-达罗排水。来源能支持什么、不能支持什么，以及进入脚本前的停止条件见
[candidate-topic-source-ledgers.md](candidate-topic-source-ledgers.md)。

候选分组、混淆变量、固定变量和真实 `prediction.json` 的缺失输入见
[six-topic-experiment-matrix.md](six-topic-experiment-matrix.md)。该矩阵是研究候选池，不是批量制作授权。

## 第三方趋势站只进入候选发现层

本轮使用授权会员账号只读检查了 [LuluJAI](https://lulujai.com/zh-CN/) 的长视频、低粉频道、搜索热词、
Shorts 和案例拆解功能。它保留 YouTube 原链接，并提供订阅、播放、时长、VPH、24H / 72H 增长、
头部贡献等候选排序线索，因此可以减少人工盲刷。

但“英语 + 历史悬疑”225 条交叉结果的前 12 条方便抽样中，只有 1 条严格符合当前事实型古代历史解释；
其余大量混入科幻、真实犯罪、政治、教程和 IP 设定。两条 YouTube 原页复核也显示站内指标存在快照
滞后，且分类不能替代人工判断。完整样本和字段分层见
[第三方趋势源评估](third-party-trend-source-assessment.md)。

因此后续固定流程为：第三方站点只输出候选 ID → YouTube 原页或官方 Data API 复核 → 人工赛道标签 →
来源账本 → 人工 Gate。站内机会度、供给缺口、动量和案例解释不得直接进入 `prediction.json` 的
`market_evidence`，除非同时保存计算口径和独立复核证据。

该抽样新增一个待扩样观察：古代日常生活中的具体身体、家庭或劳动限制可能形成强好奇问题。当前只有
单条严格样本，不能改变六题排序、默认时长或长期策略规则。

## 首轮验证设计：先证明内容机制，再谈自动化制片

### 验证目标

验证“因果问题驱动的插画历史解释”是否值得进入第二轮，而非验证播放量能否爆发。

### 建议实验边界

| 项目 | 第一期建议 |
| --- | --- |
| 周期 | 14 天；在账号、发布许可与数据读取方式准备好后开始。 |
| 数量 | 6 条，分成 3 类题目形态各 2 条。 |
| 内容类型 | 默认只测 16:9 普通视频；若选择 Shorts，则另开实验且六条全部使用同一 Shorts 规格。 |
| 语言 | 六条使用同一原始语言；自动配音或第二语言是后续独立变量，不在首轮同时测试。 |
| 固定变量 | 同一语言、同一频道、同一内容类型、同一画幅、同一旁白身份、同一画面风格、相近时长、同一事实审核与来源标注规则、相近发布窗口。发布时间只为控制早期条件，不假设它会改善长期表现。 |
| 唯一主动变量 | **题目形态**：日常制度、技术选择、决策代价，各重复两次。不要同时更换画风、配音、长度、标题风格或发布时间。 |
| 人工 Gate | 研究 / 来源审核 → 脚本论点审核 → 视觉方案审核 → 发布确认。 |
| 不做 | 不直接复刻对标视频；不批量生成；不自动发布；不在没有数据时修改 Skill。 |

### 发布前预测（需要在真实实验前填写）

推荐的可证伪假设：

> 在同一频道和同一制作形态下，围绕“一个人们必须解决的日常限制”的历史题目，比纯事件年表更容易获得较高的 72 小时平均观看比例和带有具体讨论的评论。

由于当前没有目标频道的历史基线，本轮不设置绝对播放量承诺。实际 `prediction.json` 应以频道已有
中位数为基线；若没有基线，只记录绝对数据和可比观看比例，不宣称成功或失败。

### 记录的最小数据

- 视频 ID / URL、发布时间、题目形态、标题、封面、时长、来源账本版本。
- 所有形态都记录 2 小时、24 小时、72 小时的播放、平均观看时长、平均观看比例、评论、订阅变化
  与风险 / 限制备注。2 小时只作记录，不作为胜负判断。
- 普通视频另记录展示、点击率、30 秒后仍在观看的比例、留存曲线峰值 / 低谷和同长度视频的典型留存。
  YouTube 说明留存数据通常需要 1–2 天处理，且关键留存报告要求视频至少 60 秒并达到约 100 次观看；
  未达到条件时只能记录，不得把“没有留存图”误判为内容失败。([YouTube Help](https://support.google.com/youtube/answer/9314415?hl=en-11))
- Shorts 另记录 engaged views、`Stayed to watch` 与 swiped away；其平均观看时长和平均观看比例按
  engaged views 计算，不能与普通视频 CTR 直接比较。
  ([YouTube Help](https://support.google.com/youtube/answer/12220281))
- 每条人工摘录 3 条最有信息量的评论，标注其是“具体讨论、纠错、误解、只表达情绪”中的哪类。

### 决策规则

- 普通视频的点击率必须和展示量、流量来源和同一频道的历史上下文一起看。YouTube 明确提醒高 CTR 或高平均观看
  时长本身不保证后续展示增长，也不建议在同一视频上同时测试多个标题或缩略图。([YouTube Help](https://support.google.com/youtube/answer/16767369?hl=en))
- Shorts 不上传普通视频式的自定义缩略图，只能选择视频帧用于部分展示位置；首轮不要把封面 A/B 当作
  Shorts 的默认实验变量。([YouTube Help](https://support.google.com/youtube/answer/72431))
- YPP 的普通视频路径使用有效公开观看小时，Shorts 使用近 90 天有效公开 Shorts 观看；Shorts Feed
  观看小时不计入普通视频 4,000 小时门槛。因此，不能把普通视频与 Shorts 混成一个“变现速度”指标，
  也不能用 YPP 门槛替代内容机制验证。([YouTube Help](https://support.google.com/youtube/answer/72851))
- 同一题目形态只有 1 条相对更好：仅记录观察，不能成为策略规则。
- 同一题目形态在两条里均相对领先：可作为第二轮候选；仍不能写入长期 Skill 规则。
- 相同机制在至少 3 次独立发布中重复成功，且未与画风、发布时间等变量混淆：才进入候选规则。
- 若 6 条都未显示留存或讨论上的相对优势：停止扩产，先检查钩子、标题承诺、来源与画面解释是否失败；
  不要以“再接一个模型”作为第一反应。

## 建议的下一步（仍不开发）

1. 确认目标语言、首个频道定位、频道所在地区及责任主体，以及选择普通视频还是 Shorts；默认研究建议
   是 16:9 普通视频。
2. 在取得目标频道和合法只读凭据后，再用已有频道研究 Tool 补充公开研究卡无法提供的近作、评论与频道基线；
   当前公开观察不能代替授权数据。
3. 按六题矩阵依次完成研究 brief；任何储备题触发停止条件时直接移除，不为凑足数量降低证据门槛。
4. 把本轮计划填入独立的 YouTube 实验文件。没有发布前预测，不进入发布与复盘。
5. 只有确认这条研究链确有价值后，才单独开发“频道研究 → 研究报告 → 3 个选题 → 人工确认”的
   Native Agent Skill；制作与发布不要一起塞进第一 Sprint。
