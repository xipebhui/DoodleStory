# YouTube 第三方趋势源评估：LuluJAI

更新时间：2026-08-03
状态：只读会员功能评估；可作为候选发现源，不是 YouTube 官方数据源或市场结论

## 结论先行

[LuluJAI](https://lulujai.com/zh-CN/) 对当前 DoodleStory **有参考价值**，但适合放在研究流程的最前端：

> 用它缩小候选视频、频道和关键词范围，再回到 YouTube 原页或官方 Data API 复核。

不建议现阶段把它接成 Agent 的实时硬依赖，也不能直接根据“机会度、供给缺口、动量、爆发”等站内
标签决定选题或触发生产。主要原因是：分类噪声较大、派生分数没有可见计算口径、公开页面没有可见
API / CSV 导出入口，且抽查发现播放量和订阅量快照会落后于 YouTube 原页。

本轮使用用户授权的付费账号完成只读检查。仓库不保存账号、密码、Cookie、Token、个人资料或付费信息；
没有收藏视频、加入频道夹、申请联盟、使用生图额度、购买或修改账号设置。

价值从高到低建议为：

1. **低粉频道增长榜**：同时看到频道级增长、头部贡献和代表视频，最适合排除“单条带飞”误判。
2. **长视频蓝海榜**：筛选维度完整且保留原始 YouTube 链接，适合建立人工候选池。
3. **Shorts 蓝海榜**：VPH 对发现正在加速的短视频有用，但必须回原页确认。
4. **搜索热词榜**：可提供搜索线索，但机会分数和供给口径不透明，只能作为关键词草稿。
5. **案例拆解**：内容分析粒度高，但属于解释层，不是原始数据层；部分案例同步时间停留在 4 月。

## 对当前 YouTube 研究的新增启发

### 1. 新增一个观察：古代日常生活问题

Venn Stories 样本把抽象历史包装为“古代女性如何处理一个普遍但很少被讲的问题”，同时满足：

- 具体的人类日常限制；
- 强好奇标题；
- 可用非写实解释图呈现；
- 有人类学、历史和健康背景的交叉来源需求；
- 7–8 分钟，而不是当前默认的 90–180 秒。

这只允许新增一个**待扩样观察**：`古代日常生活中的具体身体 / 家庭 / 劳动限制`。它不能立即替代
现有六题矩阵，也不能据一条视频把默认时长改为 7–8 分钟。下一轮应先收集 5–10 条同机制样本，并排除
频道已有受众、敏感标题、健康话题和视频长度等混淆变量。

### 2. 长度形成新问题，不形成新规则

本轮两条低粉异常样本都在 7–9 分钟区间，而当前验证包默认 16:9、90–180 秒普通视频。现阶段只记录：

> 若 5–10 条严格同类样本继续集中在 6–10 分钟，可在首批短形态验证之后，把“视频长度”作为下一轮
> 唯一主要变量；不能在同一组六条里同时改题型和时长。

### 3. 科幻 AI 故事应与事实历史分开

火星遗迹样本展示了“低粉 + AI 视觉 + 原创科幻长视频”的相邻方向，并在 YouTube 原页显示 AI 内容
标签。但它不属于当前来源账本驱动的事实型历史赛道。若以后研究此方向，应单独建立虚构世界观、原创性、
AI 披露和系列角色一致性流程，不与历史事实审核混用。

## 推荐接入流程

```text
LuluJAI 人工筛选
    ↓ 只输出候选 video_id / channel_id / keyword
YouTube 原页或官方 Data API 复核
    ↓ 校验标题、频道、公开指标、发布日期、时长
人工赛道标签与排除项
    ↓ 区分事实历史、虚构、真实犯罪、政治、IP、教程
来源账本与原创角度审核
    ↓ 不以 YouTube 视频作为史实来源
3 个候选题 + 人工 Gate
    ↓
发布前预测 / 小样本实验
```

候选记录最少保存：

- `observed_at`、LuluJAI 页面和筛选条件；
- YouTube `video_id` / `channel_id` 与原链接；
- 站内快照值与原页 / 官方 API 复核值分开保存；
- 第三方分类、人工分类、排除原因；
- `opportunity_score` 等派生值标记 `third_party_unverified`；
- 是否进入来源账本，以及负责复核的人。

## 是否值得开发自动接入

当前决定：**不开发**。先人工使用，原因不是功能无用，而是自动化前置证据不足。

只有同时满足以下条件，才值得讨论 Agent 接入：

1. 站点提供明确授权的稳定 API 或导出，不依赖浏览器页面抓取；
2. 有字段说明、更新时间、分页、限流、错误语义和服务条款；
3. `机会度 / 供给缺口 / 动量 / VPH` 有可理解的计算口径；
4. 连续至少 3 个观察日、每日至少 30 条抽样与 YouTube 原页 / 官方 API 对照，记录偏差；
5. 人工分类能稳定排除真实犯罪、政治、IP、虚构和标题关键词误判；
6. 第三方不可用时，研究流程明确停止并报告，不能静默用旧数据继续选题。

在此之前，LuluJAI 是一个有用的**人工雷达**，不是 DoodleStory 的策略大脑或发布链路依赖。

## 当前决策

- 允许：人工筛选、保存公开候选 ID、回原页 / 官方 API 复核、建立候选研究卡。
- 禁止：把站内分类和机会分数直接写成市场结论；自动触发脚本、生成或发布；把账号凭据写入仓库。
- 规则状态：本轮只有外部研究观察，不更新 `strategy_memory.md`，不修改 Skill。
