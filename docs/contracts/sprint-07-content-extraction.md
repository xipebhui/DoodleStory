# Sprint 07 合同：同步内容提取

## 目标

实现 `内容提取` tab 的第一版同步流程：用户粘贴抖音分享文本或链接，后端解析真实抖音 URL，同步调用同机抖音下载服务下载图文或视频，并在用户点击 `提取文案` 后同步调用 SiliconFlow 多模态能力提取原始文案。

## 范围内

- 新增最小内容提取数据库记录：
  - 保存用户原始输入、解析出的抖音 URL、媒体类型、作品 ID、下载 manifest、最终文案和创建/更新时间。
  - 保存每个下载媒体对应的资产、来源路径、媒体类型、顺序和单项提取文本。
- 新增 `FileAssetPurpose`：
  - `douyin_media`
  - `douyin_audio`
  - `douyin_metadata`
- 新增后端配置：
  - `DOUYIN_IMPORT_SERVICE_BASE_URL`
  - `SILICONFLOW_VISION_MODEL`
  - `SILICONFLOW_AUDIO_MODEL`
- 后端同步 API：
  - 健康检查代理：检查同机抖音下载服务。
  - `解析并下载`：从完整分享文本中解析抖音 URL，调用下载服务，保存媒体资产并返回详情。
  - `提取文案`：基于已下载媒体同步提取文案并保存结果。
  - 内容提取列表和详情：普通用户只访问自己的记录，Admin 可访问全部记录。
- 媒体处理：
  - 图文按下载媒体顺序逐张调用 SiliconFlow 视觉理解模型提取文字。
  - 视频用系统 `ffmpeg` 分离临时 `.mp3` 音频后调用 SiliconFlow 音频多模态模型转录。
  - 下载服务 HTTP 超时、`ffmpeg` 命令、`.mp3` 格式和最大图片数使用代码内固定默认值，不暴露为环境变量。
- 前端新增主导航 tab `内容提取`：
  - 输入抖音分享文本或链接。
  - 同步按钮 `解析并下载`。
  - 下载完成后显示媒体摘要、默认折叠的媒体预览和按钮 `提取文案`。
  - 下载图片支持点击放大预览，并可在同一批图片内左右切换。
  - 以大文本区域展示最终文案，并提供复制操作。
  - 展示最近内容提取记录。

## 范围外

- 不设计异步状态机、worker、队列、轮询或取消流程。
- 不让前端直连 `127.0.0.1:8010`。
- 不把下载服务返回的服务器绝对路径暴露给浏览器。
- 不自动创建 DoodleStory 生成任务。
- 不总结、润色、改写、扩写提取文案。
- 不做浏览器下载兜底、无 Cookie 兜底、旧子进程下载器兜底、Mock 下载结果或 Mock 提取结果。
- 不做评论采集、点赞采集、作者主页采集、音乐下载或账号素材库。

## 完成标准

- `.env.example` 包含内容提取所需配置。
- Alembic migration 可在空 SQLite 数据库上成功升级。
- 后端 API 能编译，并对下载服务不可达、无抖音 URL、下载后无媒体文件、`ffmpeg` 不可用和 SiliconFlow 失败返回明确错误。
- 前端能编译，主导航出现 `内容提取` tab，页面符合 `docs/design/content-extraction-ui-mock.png` 的主次层级。
- 已运行 `./scripts/check.sh`。
- `docs/progress.md` 记录本 sprint 实施结果、验证结果和剩余缺口。

## 验证

自动验证：

```bash
./scripts/check.sh
```

人工验证：

```bash
curl -sS http://127.0.0.1:8010/health
```

在服务可达且 SiliconFlow 配置齐全时：

1. 在 `内容提取` tab 输入完整抖音分享文本。
2. 点击 `解析并下载`，确认后端解析出真实 URL 并返回媒体预览。
3. 点击 `提取文案`，确认图文按顺序合并文本，或视频转写为原始文案。
