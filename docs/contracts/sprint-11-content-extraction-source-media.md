# Sprint 11 合同：内容提取使用下载原始媒体

## 目标

修复远程内容提取在七牛存储配置下失败的问题。下载服务已经把抖音媒体保存到同机本地路径，OCR、视频转写和图文故事总结应直接使用这份下载原始媒体，不再先上传对象存储再从公开 CDN 回拉。

## 范围内

- 内容提取媒体处理：
  - 图文 OCR 使用 `content_extraction_media.source_path` 指向的下载原始图片。
  - 图文故事总结使用 `source_path` 指向的下载原始图片。
  - 视频音频转写使用 `source_path` 指向的下载原始视频。
- 错误处理：
  - 如果下载原始媒体不存在、不是文件或为空，任务明确失败并显示错误。
  - 不静默切换到公开 CDN 回拉。
- 远程故障诊断：
  - 记录 `cdn.vdgen.shop` 超时来自对象存储公开 CDN 回读路径，不是抖音下载服务不可用。
  - 记录远程代理 `127.0.0.1:7890` 进程存在，但经代理访问 `cdn.vdgen.shop` TLS 异常；内容提取不应依赖该代理路径。
- 更新 `docs/spec.md` 和 `docs/progress.md`。

## 范围外

- 不改变抖音下载服务接口。
- 不改变文件资产上传和前端媒体展示仍使用 DoodleStory 资产的规则。
- 不为 CDN 回读增加代理兜底。
- 不调整 mihomo、XG 或 ApexerAPI 代理配置。
- 不迁移历史失败任务或清理已经上传但事务回滚的对象存储孤儿文件。

## 完成标准

- 内容提取 OCR/总结代码不再调用七牛公开 CDN 来读取刚下载的媒体。
- 下载原始媒体缺失时返回明确错误。
- `./scripts/check.sh` 通过。
- 远程部署后重启后端服务。

## 验证

自动验证：

```bash
./scripts/check.sh
```

远程验证：

1. 检查远程后端日志中目标任务的 `processing_error_message`。
2. 检查 `127.0.0.1:7890` 代理进程和 CDN 访问结果。
3. 部署后确认后端健康检查正常。
