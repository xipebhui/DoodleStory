# Sprint 16 合同：任务创建弹窗与风格宫格选择

## 目标

优化任务创建体验：创建任务使用居中弹窗，输入模式、参考人物、图片数量和风格选择的顺序更符合用户决策路径；风格过多时可以通过二级弹窗展开选择。

## 范围内

- 任务创建从侧边抽屉改为居中弹窗。
- 完整故事 / 故事方案改为带说明的点击选择：
  - 完整故事说明会保持故事不变，并提示用户只提交故事本身，不要混入其他内容。
  - 故事方案说明可以提交故事设计、要求或简化想法。
- “使用参考人物”默认勾选，并移动到风格选择之前。
- 图片数量选择移动到风格选择之前。
- 风格选择改为紧凑宫格，创建弹窗中展示更多风格。
- 当风格数量较多时，提供“展开更多风格”的二级弹窗，展示完整风格宫格并可直接选择。
- 更新规格、进度和当前合同记录。

## 范围外

- 不修改任务创建 API。
- 不修改后端任务执行逻辑。
- 不改变风格管理页的创建/编辑风格流程。
- 不引入新的组件库或路由框架。

## 完成标准

- 打开创建任务时，“使用参考人物”默认勾选。
- 创建任务 UI 是居中弹窗，不再从侧边滑出。
- 用户能在创建弹窗内直接看到紧凑风格宫格，并能通过展开弹窗选择更多风格。
- 提交任务仍按已有 API 创建任务并进入新任务详情 URL。
- `npm run build` 和 `./scripts/check.sh` 通过。

## 验证

自动验证：

```bash
npm run build
./scripts/check.sh
```

浏览器验证：

1. 打开 `/tasks`，点击“创建任务”。
2. 确认创建任务以居中弹窗出现，参考人物默认勾选。
3. 确认模式选择说明、图片数量和风格宫格顺序符合合同。
4. 点击“展开更多风格”，确认二级弹窗可选择风格并回填到创建表单。
