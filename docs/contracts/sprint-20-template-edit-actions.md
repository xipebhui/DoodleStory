# Sprint 20 合同：模板编辑入口与图片模型输入

## 目标

修复模板管理页中编辑入口不明显的问题，并明确模板里的图片模型由用户手动填写，不使用下拉选择。

## 范围内

- 模板卡片标题区直接展示“编辑模板”按钮。
- 保留模板测试动作，但不让编辑入口隐藏在较弱的位置。
- 模板表单中的图片模型字段保持文本输入。
- 图片模型字段增加明确标签和说明：手动输入模型名，不使用下拉选择。
- 更新规格和进度记录。

## 范围外

- 不新增独立图片模型管理模块。
- 不新增模型枚举、模型 API 或模型下拉数据源。
- 不新增当前仓库尚不存在的人物库、产品库管理 API。
- 不修改任务生成逻辑。

## 完成标准

- 用户在模板列表卡片上可以直接看到编辑入口。
- 创建或编辑模板时，图片模型字段是文本输入框。
- `npm run build` 和 `./scripts/check.sh` 通过。

## 验证

自动验证：

```bash
npm run build --prefix frontend
./scripts/check.sh
```

功能验证：

1. 浏览器打开 `/styles`，确认模板卡片标题行可见“编辑模板”按钮。
2. 打开模板编辑弹窗，确认图片模型是输入框且有“手动输入模型名，不使用下拉选择”的说明。
