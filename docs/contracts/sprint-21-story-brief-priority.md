# Sprint 21 合同：故事方案用户要求优先级

## 目标

提高故事方案模式中用户输入的约束强度，确保用户写出的画面要求、构图要求、禁止事项和重点强调优先于默认创作建议和风格规则。

## 范围内

- 强化故事方案 storyboard prompt 中 `brief_text` 的优先级。
- 明确用户需求与风格规则、默认分镜方法或剧情增强建议冲突时，优先满足用户需求。
- 明确用户写出的上下分区、左右分区、分屏、单页构图、字体大小、必须出现和不要出现等要求必须进入对应 panel 设计。
- 更新规格和进度记录。

## 范围外

- 不新增规则解析器。
- 不改数据库结构。
- 不新增前端字段或新的任务创建表单。
- 不改变完整故事模式的原文保留规则。

## 完成标准

- 故事方案 prompt 明确 `brief_text` 是最高创作约束。
- 用户显式要求与风格或默认创作建议冲突时，prompt 明确以用户要求为准。
- `./scripts/check.sh` 通过。

## 验证

自动验证：

```bash
./scripts/check.sh
git diff --check
```

人工验证方向：

1. 创建故事方案任务，输入包含“上格/下格”或“左右两部分”的画面要求。
2. 检查 `prompt_trace` 或任务详情中的 panel prompt，确认对应构图要求被保留在 `visual_prompt` 中。
