# Sprint 26 合同：内容提取结果提交为分镜生图任务

## 目标

在内容提取详情中增加 `提交任务` 入口，把已经按页提取出的漫画内容直接带入任务创建流程。该入口使用新的第三种输入模式 `提取分镜`，只把内容提取结果结构化为可生图 panels，不走现有 `故事方案` 的二次创作和重写。

## 范围内

- 前端内容提取详情的 `复制内容` 旁边增加 `提交任务`。
- 点击 `提交任务` 后跳转到任务页，自动打开创建任务弹窗，并预填内容提取结果。
- 任务创建弹窗增加第三种输入模式：`提取分镜`。
- 后端新增 `story_input_mode=extracted_storyboard`。
- `提取分镜` 模式调用专用 LLM prompt，把内容提取结果按页解析为 panels。
- 专用 prompt 必须保留页序、旁白、对话、内心 OS 和分格/多栏布局，不扩写、不总结、不合并页。
- 最终生图 prompt 区分旁白、对白和内心 OS 的画面表现方式，并要求图片中文字字号偏大、清晰可读。
- 多栏或分格信息进入 `TaskPanel.text_layout`，并写入最终生图 prompt。

## 范围外

- 不新增来源追踪数据库字段。
- 不删除或迁移历史任务。
- 不把内容提取结果自动提交任务，必须由用户点击 `提交任务`。
- 不把 `提取分镜` 作为 `故事方案` 的别名或兜底。
- 不引入新的外部队列、Mock 结果或静默跳过解析失败。

## 完成标准

- 内容提取详情中有 `提交任务` 按钮，且仅在存在内容提取结果时可用。
- 从内容提取详情提交后，任务创建弹窗预填文本并选中 `提取分镜`。
- `提取分镜` 创建出的任务显示为第三种模式，不显示成 `完整故事` 或 `故事增强`。
- worker 能把提取内容解析成 panels，并直接进入人物参考和生图流程。
- 最终 prompt 包含旁白框、对白气泡、内心 OS 样式、字号偏大和多栏分格布局规则。
- `backend/.venv/bin/python -m compileall backend/app`、`npm run build --prefix frontend`、`git diff --check` 和 `./scripts/check.sh` 通过。
