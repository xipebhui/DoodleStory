# Sprint 10 合同：工作台二级路径路由

## 目标

为 DoodleStory 主工作台页面增加稳定的二级路径，避免用户在任务、内容提取、风格或设置页面刷新后回到默认任务页。页面路径应能复制、刷新，并支持浏览器前进后退。

## 范围内

- 前端主导航改为 URL 驱动：
  - 任务页：`/tasks`
  - 内容提取页：`/content-extractions`
  - 风格页：`/styles`
  - 设置页：`/settings`
- 侧边栏主导航使用真实链接语义。
- 浏览器刷新应保留当前页面。
- 浏览器前进、后退应切换对应工作台页面。
- 根路径 `/` 对已登录用户归一到 `/tasks`。
- 未匹配的前端路径显示明确的页面不存在状态。
- 更新 `docs/spec.md` 和 `docs/progress.md`。

## 范围外

- 不引入 React Router 或其他路由依赖。
- 不拆分当前 `frontend/src/main.tsx`。
- 不改变任务、内容提取、风格和设置页面内部的数据请求接口。
- 不新增任务详情、内容提取详情或风格测试的深层资源路径。
- 不改变认证接口和登录流程。

## 完成标准

- 在 `/content-extractions` 刷新后仍显示内容提取页面。
- 在 `/styles` 刷新后仍显示风格页面。
- 点击侧边栏导航会更新浏览器地址。
- 浏览器前进后退可以恢复对应页面。
- `npm run build` 通过。
- `./scripts/check.sh` 通过。

## 验证

自动验证：

```bash
./scripts/check.sh
```

人工验证：

1. 登录后点击内容提取，确认地址变为 `/content-extractions`。
2. 刷新页面，确认仍停留在内容提取页面。
3. 点击风格，确认地址变为 `/styles`。
4. 刷新页面，确认仍停留在风格页面。
5. 使用浏览器后退和前进，确认页面与地址同步变化。
