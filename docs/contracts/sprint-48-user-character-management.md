# Sprint 48 合同：用户角色管理与快速角色参考

## 目标

新增用户隔离的「角色管理」能力，并在创建任务时根据用户输入文本快速提取角色名字。用户可以只给关键角色补充参考图和描述；用户显式绑定的角色作为固定角色进入后续人物参考链路，故事中未绑定但被任务人物提取识别为主要人物的角色仍会生成任务内临时参考图。

## 范围内

- 新增「角色管理」tab，支持当前用户自己的角色列表、详情、创建、编辑和删除。
- 角色字段包含名字、参考图和描述；角色参考图不会展示给其他用户。
- 保存角色参考图后，后端在后台调用 SiliconFlow 视觉模型生成可编辑的角色外观描述，并保存到角色 `description`；该后台识别失败时最多重试 3 次，不阻塞用户保存角色。后续生成任务复用已保存的描述，不为同一角色重复调用 VL。
- 角色删除采用软删除；历史任务使用任务内快照，不受角色后续修改或删除影响。
- 创建任务默认开启人物参考链路；即使用户不点击 `提取角色` 或没有绑定固定角色，任务执行时也会提取主要人物并生成任务内临时角色参考图。
- 创建任务弹窗通过醒目的 `AI 提取角色` 操作调用硅基流动 `Qwen/Qwen3.6-27B` 提取角色名字；前端由用户显式点击触发，作用是提前展示角色名、删除误识别角色或绑定固定角色。
- 创建任务里展示角色名卡片和「添加角色」卡片；提取出的角色名支持从本次任务中删除；用户可以从带参考图的角色库列表选择角色，或新建角色并绑定。
- 任务创建接口接收用户显式绑定的角色，并校验角色归属当前用户。
- 绑定角色会快照到任务内人物参考结构；这些角色的参考图作为固定人物参考图进入 panel 生图。
- 固定角色和任务临时角色进入最终生图 prompt 编译时携带角色描述、外观锚点和参考强度规则：角色身份 > 当前剧情动作/情绪 > 风格表现方式 > 风格模板默认人物外观。
- 最终 panel 生图 prompt 不再由代码直接拼接参考和分镜块，而是调用 LLM 读取全局角色表、每页分镜中间态、图片内文字、风格信息和参考图顺序后输出完整画师指令；`prompt` 风格参考模式下，后端会在 LLM 画师指令外层显式拼接完整风格模板，用于加强线上画风一致性。
- 最终 prompt 编译层必须处理角色外观与分镜/风格模板默认人物外观的冲突，并保证固定角色和临时角色在同一任务内按同一规则保持全局一致。
- 未绑定或未设置形象的角色不写入用户角色库；如果任务人物提取识别为主要人物，则生成任务内临时参考图并显示在任务详情人物参考列表中。
- 新增可选「融入故事」接口，用于用户新增一个原文中没有的角色时，显式调用 LLM 把角色自然并入故事文本。
- 手动添加角色名只需要填写名称，不要求立刻上传参考图。
- 更新产品规格、进度记录、后端测试和前端创建任务体验。

## 范围外

- 不做复杂角色映射确认页。
- 不在用户输入后自动调用创建页角色名提取接口；只有用户显式点击 `AI 提取角色` 才调用。任务执行阶段的临时角色提取仍默认开启。
- 不把未绑定角色保存为用户角色资产；临时参考图只属于当前任务。
- 不引入外部队列、状态机或跨任务角色一致性评分。
- 不改变风格管理、积分规则和普通任务下载行为。

## 完成标准

- 普通用户只能看到、更新、删除和绑定自己的角色；绑定其他用户角色时明确返回权限错误。
- 创建任务输入故事并点击 `提取角色` 后能显示 AI 提取的角色名。
- 创建任务即使未点击 `提取角色`、未绑定固定角色，也会保存为 `use_character_references=true` 并生成 `extract_characters`、`generate_character_references` 步骤。
- 用户绑定的角色会在任务详情的人物参考区域展示，并作为人物参考图传入生图链路。
- 未绑定但被任务人物提取识别到的主要角色会生成任务内临时参考图，并在任务详情人物参考区域展示。
- 正式任务和单 panel 修改都会先生成分镜中间态，再由最终 prompt 编译 LLM 输出生图 prompt；编译失败时任务或图片版本明确失败，不静默回退到字符串拼接。
- `./scripts/check.sh` 通过，或明确记录未通过原因。

## 风险 / 说明

- 角色名提取服务于创建页快速绑定，不作为最终剧情分析；调用失败时接口明确返回错误，不静默切回规则提取。
- 固定角色在完整故事模式下会复用现有 panel prompt 生成阶段判断角色出现位置；故事方案和提取分镜模式会用角色名字在 panel 文本和画面提示词中做确定性匹配。
- 「融入故事」是用户显式动作，完整故事模式不会在用户未触发时改写原文。
