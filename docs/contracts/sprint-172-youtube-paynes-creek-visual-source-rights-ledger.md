# Sprint 172：YouTube Paynes Creek 视觉来源与授权清单

状态：已完成

## 背景

Sprint 170 已把古典期玛雅 Paynes Creek 盐业选为第一条本地样片候选，并建立历史事实来源账本；
Sprint 171 结束频道扩样，确认下一步应进入单条样片的视觉证据与授权 Gate。当前仍不能把“论文能访问”
等同于“论文图片可复用”，也不能用现代盐业、旅游照或泛玛雅图像替代公元 600–900 年伯利兹南部的
具体场景。

## Goal

为 `V1–V7` 每个候选场景建立可回查的视觉证据与授权清单，分别判断历史准确性和商业视频复用权，
并把每项素材标记为：

- `reuse_allowed`：来源明确允许复用，且已记录许可、署名和限制；
- `reference_only`：只用于理解事实，不复制、裁切、描摹或合成进成片；
- `permission_required`：如要直接使用，必须先取得权利人许可；
- `avoid`：年代、地域、语义或授权风险过高，不进入当前样片。

## In Scope

- 核查同行评议原始研究、官方博物馆 / 政府 / 开放收藏和明确授权页面。
- 覆盖区域地图、卤水浓缩、盐厨房、制盐陶器、散盐 / 盐饼、独木舟 / 船桨、内陆交换、水下考古、
  人物与服饰。
- 记录许可证链接、署名要求、第三方图表例外和需要在制作时再次核验的条件。
- 对 `V1–V7` 分别给出“可进入原创绘制”“需继续研究 / 许可”“替换”或“删除”决定。
- 优先设计不直接嵌入第三方图片的原创示意方案。

## Out of Scope

- 不写视频脚本、旁白、逐镜分镜或正式标题。
- 不生成图片、音频、视频，不创建 DoodleStory 生成任务。
- 不下载或提交第三方图片，不获得权利人许可，不执行公开发布。
- 不把本清单表述为法律意见或永久授权保证。
- 不创建发布实验、预测或策略规则。
