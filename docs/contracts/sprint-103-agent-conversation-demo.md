# Sprint 103：Agent 会话前端交互 Demo

## 背景

当前需要先验证 Agent 产品的前端交互，而不是实现真实 Agent 后端或沿用现有任务 Pipeline。用户希望直接看到如何开启新对话、继续历史对话、在对话中查看任务，以及选择某张图片后回到对话继续修改。

## 本次范围

- 在 `docs/design/agent-conversation-demo/` 提供一个独立、可直接运行的前端 Demo。
- 展示新建对话、历史对话搜索与切换、对话内任务卡片。
- 展示任务详情、Panel 选择、把 Panel 带回对话输入区。
- 展示风格、角色和任务资源的 `@` 引用入口。
- 使用明确标注的确定性本地演示数据，不连接真实后端或模型。
- 同步修正 Agent 前端设计 Brief，使会话成为首屏主体，分镜成为按需打开的任务详情。

## 不在本次范围

- 不修改现有 React 产品页面。
- 不实现 Agent 循环、工具调用、持久化或真实任务执行。
- 不接入 LLM、VL、生图 Provider、积分或计费。
- 不把本地演示状态描述为正式产品能力。

## 验收标准

1. 用户能从左侧新建一个空白对话并发送示例需求。
2. 用户能切换到历史对话，再返回原对话继续查看消息。
3. 漫画任务以卡片形式存在于所属对话中，并显示进度。
4. 用户能打开任务详情、选择 Panel，并把它带回对话输入区。
5. 用户能通过资源入口添加风格、角色或任务上下文。
6. Demo 在桌面浏览器可运行，控制台无错误；脚本语法与仓库差异检查通过。

## 交付边界

这是设计演示，不是生产实现。所有动态变化均为前端确定性状态，并在界面与说明中明确标注。
