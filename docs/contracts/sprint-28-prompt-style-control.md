# Sprint 28 合同：提示词风格控制与参考图展示化

## 目标

将风格控制从“风格参考图作为生图输入”调整为“风格模板提示词控制”。风格参考图继续保存在风格库中，用作样张、封面和用户理解视觉方向，不再传入生图模型，避免模型过度复刻参考图人物或构图。

## 范围内

- 风格测试只把测试文本和风格提示词组合后提交统一生图 Gateway，不再要求或传入风格参考图。
- 人物参考图生成只依赖人物设定和风格提示词，不再把风格参考图作为输入。
- 任务 panel 生图：
  - 未开启人物参考时，统一 Gateway 请求不携带参考图。
  - 开启人物参考时，只携带该 panel 绑定的人物参考图。
  - 最终 prompt 中只声明人物参考图，不再声明风格参考图。
- 单 panel 修改重新生图遵守同样规则。
- 前端风格页文案明确参考图是样张展示，风格控制来自模板提示词。
- 更新产品规格、README 和进度文档。

## 范围外

- 不删除风格参考图表、上传接口、封面逻辑或历史参考图资产。
- 不改变人物参考图能力。
- 不新增模型兜底、provider 降级或 mock 结果。
- 不迁移历史任务或历史生成结果。
- 不改变统一生图 Gateway 的多参考图能力；人物参考图仍可通过 `images` 数组传入。

## 完成标准

- 风格测试在没有参考图时也能创建 provider 请求。
- 正式任务未开启人物参考时，provider 请求的 `reference_paths` 为空。
- 正式任务开启人物参考时，provider 请求只包含人物参考图。
- 代码中不再出现“风格至少需要一张参考图”的生图前置校验。
- `backend/.venv/bin/python -m compileall backend/app`、`npm run build --prefix frontend`、`git diff --check` 和 `./scripts/check.sh` 通过。
