# Sprint 03 合同：任务人物参考图

## 目标

在创建任务时支持“使用参考人物”。开启后，任务会在故事切分之后识别主要人物及其不同年龄/外形阶段，先生成这些人物的参考图，再在每个 panel 生图时按稳定顺序携带相关人物参考图，以提升跨 panel 的人物一致性。

## 范围内

- 任务创建接口和前端创建弹窗增加 `use_character_references`。
- 数据库新增任务人物、人物外形阶段、panel 与人物阶段引用关系，并在任务表保存是否启用人物参考。
- LLM 新增：
  - 主要人物与年龄/外形阶段提取。
  - 带人物引用的 panel prompt 生成。
- 图片生成流程新增：
  - 人物参考图生成步骤。
  - panel 生图时按“人物参考图在前，风格参考图在后”的顺序传入参考图。
  - prompt 中明确声明“参考图 1/2/…”对应的人物。
- 任务详情页只展示人物参考图和姓名/阶段，不展示内部识别 prompt、panel 引用细节或完整人物设定。
- 普通任务保持原流程，人物参考任务使用独立策略对象处理人物上下文，避免 worker 内部到处写分支。

## 范围外

- 不提供人物设定人工编辑。
- 不提供人物参考图单独重试或删除。
- 不在前端展示完整人物分析、出现 panels、内部 usage note。
- 不引入外部队列或独立 worker。
- 不做角色一致性质量评分。

## 完成标准

- 未开启人物参考时，现有任务流程和结果不变。
- 开启人物参考时，任务总步骤包含人物提取和人物参考图生成。
- 主要人物/阶段被持久化，人物参考图保存为本地资产。
- 每个 panel 生图时只携带该 panel 涉及的人物参考图，且顺序稳定。
- 最终 prompt 明确引用参考图编号和人物姓名/阶段。
- 任务详情只展示人物参考图、姓名和阶段。
- 已运行 `./scripts/check.sh`。

## 验证

```bash
./scripts/check.sh
```

人工检查：

- 创建普通任务，确认不展示人物参考区域，流程仍为原有步骤。
- 创建开启人物参考的任务，确认任务详情展示人物参考图和姓名/阶段。
- 查看日志，确认人物参考图先生成，panel 生图参考图顺序为人物图在前、风格图在后。

## 风险 / 备注

- 如果开启人物参考但 LLM 未识别到主要人物，任务会失败并显示明确错误，不静默降级为普通生图。
- 当前不实现人物参考图失败后的单独重试，后续可以在版本化图片和任务重试策略成熟后补充。
