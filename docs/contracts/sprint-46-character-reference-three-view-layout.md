# Sprint 46 合同：人物参考图三视图布局

## 目标

收紧人物参考图生成提示词，让每张人物参考图固定采用角色设定图布局：上半部分为正面主图，下半部分为两个侧视图。该布局用于提高后续多张分镜中同一人物的外观一致性。

## 范围内

- 调整人物参考图 prompt 模板，明确上方正面主图、下方两个侧视图的布局。
- 要求三张视图使用同一人物、同一服装、同一发型和同一稳定外观锚点。
- 增加后端测试覆盖人物参考图 prompt 中的三视图布局要求。
- 更新产品规格和进度记录。

## 范围外

- 不改变人物提取 JSON 结构、人物 appearance 拆分规则或数据库 schema。
- 不改变人物参考图生成模型、图片 Provider 路由、扣费逻辑或任务状态机。
- 不为生成失败增加兜底、重试之外的降级逻辑、占位图或 Mock 结果。

## 完成标准

- 人物参考图 prompt 明确包含“上半部分/上方正面主图”和“下半部分/下方两个侧视图”。
- prompt 明确要求两个侧视图分别展示左侧和右侧，且与正面主图保持同一人物设定。
- 相关后端测试通过。
- `./scripts/check.sh` 通过，或明确记录未通过原因。

## 风险 / 说明

- 角色参考图仍然只画一个人物；三视图是同一人物的多个视角，不是多个角色。
- 该改动只改变参考图生成提示词，不改变后续 panel 生图携带人物参考图的顺序和方式。
