# Sprint 171：Buried Empires 具体文明结构对照

## 状态

Completed

## Goal

使用统一频道拆解卡刷新 Buried Empires 当前官方公开视频窗口，检验其高度具体的 Rome、Sparta、
Mongols 等文明 / 人物标题是否提供了可以脱离战争、惩罚与酷刑题材迁移的叙事边界、来源公开方式和
机制视觉；完成前五频道横向审计指定的最后一个强结构对照，并据此决定是否停止扩频道。

## In Scope

- 通过 YouTube 官方 RSS 读取当前最近 12 条，记录频道 ID、视频 ID、标题和发布时间。
- 逐条核对官方视频页的时长、当前播放、直播状态、完整公开描述、来源栏、直接链接、章节和边界语言。
- 核对官方 About 页当前可见的订阅、总播放、视频数、加入时间、Handle 与公开频道定位。
- 临时下载当前 12 条官方最高可用分辨率缩略图，核对尺寸、文字、主体、构图、视觉具体性与暴力风险；
  图片不提交仓库。
- 统计发布节奏、时长、标题具体性、文明 / 人物分布、暴力承诺、播放集中度和来源可审计性。
- 明确区分“具体文明结构的研究价值”和“暴力题材的产品适配度”，不把频道表现写成因果。
- 根据预设停止规则决定：停止剩余频道卡，或只保留 Explain In Paint 作为一个窄补充候选。
- 更新频道拆解索引、前五频道横向审计、YouTube 索引、研究日志和项目进度。

## Out of Scope

- 不抓取全频道 132 条视频，不下载视频、字幕、脚本或评论，不审计视频内全部史实。
- 不把当前播放除以视频年龄计算增长速度，不推断 CTR、留存、流量来源、收入、成本或订阅转化。
- 不复制标题、缩略图、写实人物、暴力场面、脚本、镜头或素材，不把战争 / 惩罚包装升级为规则。
- 不创建 Paynes Creek 实验、英文脚本、分镜、图片、语音、视频或发布任务；制作验证另开独立 Sprint。
- 不更新 `strategy_memory.md`、Skill、六题排序、默认时长、业务代码、数据库或前端。

## Done Means

- 官方 RSS 当前 12 条均有可回查链接和观察时间，视频 ID 唯一，官方频道身份一致。
- 每条均记录标题、发布日期、时长、当前播放、直播状态、题型、历史具体性和来源包装。
- 12 张缩略图已临时核对原始尺寸、文字、主体、构图与风险；仓库不保留第三方图片。
- 给出频道内发布节奏、时长、播放集中度与异常值，并显式保留视频年龄和曝光不可得边界。
- 统计明确历史边界、文明 / 人物、战争 / 惩罚、章节、来源栏和直接外部链接的出现率。
- 至少列出 3 项可迁移结构、3 项不可复制风险和 3 个公开数据无法回答的问题。
- 按固定停止规则决策：如果具体性主要依赖文明名 + 暴力强度，且来源 / 视觉没有提供可脱离暴力的新机制，
  则停止剩余频道卡；否则只记录一个明确的窄补充问题，不恢复机械拆解名单。
- 控制器状态校验、本地 Markdown 链接、敏感字符串扫描和 `git diff --check` 通过。
