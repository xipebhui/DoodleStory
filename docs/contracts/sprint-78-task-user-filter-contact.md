# Sprint 78 任务用户筛选与联系入口

## 背景

运营排查线上任务时，需要在任务列表中按用户缩小范围；同时工作台需要一个稳定的联系入口，展示微信二维码，方便用户遇到生成、风格或积分问题时联系维护者。

## 范围

- 任务页增加管理员可见的用户下拉筛选。
- 前端任务列表请求把选中的用户 ID 传给已有任务列表接口。
- 工作台增加 `/contact` 联系我们页面，并在侧边栏导航中展示入口。
- 联系页展示微信二维码和微信联系文案。

## 不做

- 不新增后端任务列表过滤接口；复用现有 `user_id` 查询参数。
- 不新增用户搜索后端能力；复用现有管理员用户列表接口。
- 不实现在线客服、消息发送或外部客服系统集成。

## 验收标准

- 管理员进入任务页时，可以从下拉中选择用户并只查看该用户的任务。
- 普通用户看不到用户筛选控件，仍只能查看自己的任务。
- 点击侧边栏 `联系我们` 后进入 `/contact`，刷新页面后仍停留在联系页。
- 联系页展示微信二维码，移动端布局不溢出。
- `npm run build --prefix frontend`、`./scripts/check.sh` 和 `git diff --check` 通过，或在进度中记录未通过原因。
