# Sprint 32 合同：风格删除与图片预览加载态

## 目标

修复风格无法删除的问题，并优化图片左右切换时的加载体验。切换图片时如果新图还没有加载完成，界面必须先显示空白加载态，不能继续显示上一张图片导致文字和图片不一致。

## 范围内

- 风格删除支持历史引用场景：
  - 没有任务或测试引用的风格继续物理删除。
  - 已被历史任务或风格测试引用的风格改为软删除，从风格库列表隐藏，并释放原风格名。
- 新建任务、重试任务、编辑风格、上传参考图和风格测试都不能使用已删除风格。
- 图片通用懒加载组件在图片 URL 切换时重置加载状态，先显示空白/加载背景，再显示新图。
- 前端删除风格确认文案改为说明历史任务保留风格快照。
- 增加数据库迁移和单元测试。
- 核对本地与远程对象存储配置是否已切到国内新 bucket/domain。

## 范围外

- 不删除历史任务、历史生成图片、历史风格测试或文件资产。
- 不迁移旧 bucket 中已经生成的历史文件。
- 不改变任务详情和内容提取详情的预览布局。
- 不把对象存储密钥写入文档、日志或提交内容。

## 完成标准

- 被历史任务引用的风格点击删除后不再出现在风格库。
- 未引用风格点击删除后数据库行被移除。
- 图片预览切换时不会继续显示上一张图。
- 本地和远程对象存储运行配置核对完成；如远程未切到国内新配置，则完成切换并重启服务。
- `backend/.venv/bin/python -m unittest discover -s backend/tests`、`backend/.venv/bin/python -m compileall backend/app`、`npm run build --prefix frontend`、`git diff --check` 和 `./scripts/check.sh` 通过。
