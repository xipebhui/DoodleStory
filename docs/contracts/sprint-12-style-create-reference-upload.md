# Sprint 12 合同：风格创建时上传参考图

## 目标

修复风格创建流程中无法上传参考图的问题。用户在新建风格时应能同时选择参考图，提交后系统先创建风格，再把已选择的参考图上传到该风格。

## 范围内

- 前端风格抽屉：
  - 新建风格时显示参考图上传区域。
  - 新建状态下可选择多张 PNG、JPEG 或 WebP 参考图。
  - 提交创建后，按已选择文件上传到新创建的风格。
  - 编辑状态保持原有即时上传和删除参考图能力。
- 反馈与错误：
  - 创建并上传成功后显示明确成功信息。
  - 如果风格创建成功但参考图上传失败，保留在编辑状态并显示明确错误，方便用户重试上传。
- 更新 `docs/progress.md`。

## 范围外

- 不改变后端风格 API。
- 不新增草稿图片临时上传接口。
- 不引入前端全局状态或组件拆分。
- 不改变风格测试流程。

## 完成标准

- 点击“新建风格”时，抽屉内可以看到“参考图”上传位置。
- 新建时选择参考图后，文件名/数量在抽屉内可见。
- 创建成功后参考图会上传到新风格，并在风格列表/编辑抽屉中可见。
- `npm run build` 和 `./scripts/check.sh` 通过。

## 验证

自动验证：

```bash
./scripts/check.sh
```

人工验证：

1. 打开风格页，点击“新建风格”。
2. 确认创建抽屉中存在“参考图”上传位置。
3. 选择一张或多张图片，确认待上传文件名可见。
4. 填写基础信息并创建，确认参考图上传到新风格。
