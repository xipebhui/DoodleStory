# Sprint 45 合同：统一分镜生图格式

## 目标

把完整故事、故事方案和提取分镜三条任务链路在生图前统一到稳定的页式分镜格式：`第X页`、`【分格】`、`画面`、`旁白`、`对话`、`内心OS`。完整故事继续保持原文逐字切分；故事方案继续允许按用户方案增强分镜；提取分镜继续只结构化内容提取结果。

## 范围内

- 调整完整故事 panel prompt 规则，让 LLM 只负责画面设计，后端用统一页式分镜块承载原文旁白。
- 调整故事方案 storyboard prompt，让输出更接近提取分镜的结构：每页明确画面、分格布局、旁白、对白和内心 OS。
- 调整正式 panel 最终生图 prompt 组装，让三种输入模式都使用同一套页式分镜块。
- 增加后端测试覆盖三种模式的最终 prompt 结构。
- 更新产品规格和进度记录。

## 范围外

- 不改变任务输入模式、数据库 schema、任务状态机或队列流程。
- 不改变内容提取下载、视觉理解、DY 爆款复刻自动创建任务流程。
- 不引入兜底策略、占位分镜、Mock 结果或静默忽略 LLM/Provider 错误。
- 不让完整故事模式改写、扩写、摘要或删除用户原文。

## 完成标准

- 完整故事最终 prompt 包含 `第N页`、`【分格】单页`、`画面`、`旁白`、`对话：无`、`内心OS：无`，且旁白逐字等于 panel 原文。
- 故事方案最终 prompt 使用同一套页式分镜块，并能保留 `text_layout`、旁白、对白和内心 OS。
- 提取分镜最终 prompt 继续使用同一套页式分镜块，不新增封面、不合并页。
- 后端测试覆盖关键 prompt 组装行为。
- `./scripts/check.sh` 通过，或明确记录未通过原因。

## 风险 / 说明

- 字段名用于给图片模型稳定理解结构，但最终 prompt 必须提示不要把“画面/旁白/对话/内心OS”等字段名画进图片。
- 完整故事模式的原文保留优先级高于统一格式；任何改动都不能破坏 panel 拼接后逐字等于用户输入这一约束。
