# Sprint 80: 生图结果比例校验重试

## 背景

线上任务 `b0d41aea74ce4c3188f076a334491290` 的 panel 2 目标为当前任务风格比例，但实际生成结果出现了 `9:16` 图片。现有逻辑主要在 prompt 和部分 provider 参数中表达比例要求，缺少对 Provider 返回结果的后置尺寸校验。

## 范围

- 正式任务 panel 生图在保存资产前读取返回图片尺寸。
- 单 panel 修改重新生图也执行同样的尺寸校验。
- 如果返回图片比例与任务目标比例不一致，使用同一模型、同一 prompt 和同一参考图重新生成。
- 比例重试次数沿用当前图片 job 的 `max_attempts`，重试耗尽后明确失败。
- 保存成功资产时记录 `width` 和 `height`，方便后续排查。

## 非范围

- 不切换图片 provider 或图片模型。
- 不新增模型兜底、降级或 mock 结果。
- 不修改角色参考图和风格测试的重试策略。
- 不改变积分定价；只有最终成功产出的合格图片扣费。

## 验证

- 新增单元测试覆盖比例不符时不保存资产。
- 新增单元测试覆盖 panel 生图比例不符后重新请求并成功。
- 运行相关后端测试与项目检查脚本。
