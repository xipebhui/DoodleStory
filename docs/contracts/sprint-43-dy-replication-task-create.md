# Sprint 43 合同：DY 爆款复刻一键创建任务

## 目标

把内容提取接入任务创建前置流程，让用户在创建任务时选择 `DY爆款复刻` 后只提交一次抖音分享文本或链接。系统先完成内容提取，再自动用提取结果创建 `提取分镜` 生图任务，减少“先提取、再提交任务”的重复操作。

## 范围内

- 任务创建弹窗新增 `DY爆款复刻` 输入模式。
- 新增后端接口接收抖音分享文本和任务创建参数。
- 内容提取后台流程成功得到 `extracted_text` 后，自动创建 `extracted_storyboard` 生成任务并入队。
- 内容提取记录保存关联生成任务 ID、自动创建任务状态和错误信息。
- 内容提取详情保留手动 `提交任务` 入口，作为编辑提取结果后的高级路径。
- 前端提交 DY 爆款复刻后轮询内容提取记录；关联任务创建成功后跳转到任务详情。
- 更新产品规格和进度记录。

## 范围外

- 不新增新的分镜解析模型或生图模型路径。
- 不改变普通内容提取入口的默认行为。
- 不把内容提取升级为外部队列或持久工作流。
- 不自动编辑、总结或润色 `extracted_text`。
- 不改变现有 `提取分镜` 任务执行链路。

## 完成标准

- 普通 `/tasks` 创建继续复用原有校验和任务入队行为。
- `DY爆款复刻` 创建会先产生内容提取记录，完成后自动产生 `story_input_mode=extracted_storyboard` 的生成任务。
- 自动创建任务失败时，内容提取记录能显示独立的任务创建错误，不吞掉已经提取出的内容。
- 前端一次提交后能看到处理中状态，并在生成任务创建后跳转到 `/tasks/{task_id}`。
- 后端测试覆盖自动创建任务状态写回和普通任务创建复用。
- `./scripts/check.sh` 通过，或明确记录未通过原因。

## 风险 / 说明

- 当前内容提取仍是同进程后台任务；服务重启会把处理中记录标记失败，本次不改变这个工作流级别。
- 复刻任务使用用户提交时选择的风格快照；后续风格修改不会影响已创建任务。
