# Sprint 47 合同：DY 来源元信息随任务下载

## 目标

抖音下载服务在 `/api/v1/download` 响应中新增标题、描述和标签后，DoodleStory 需要保存这些来源元信息。通过 `DY爆款复刻` 自动创建的生成任务在用户下载图片压缩包时，需要额外包含 `meta.txt`，方便用户同时拿到原作品标题、描述和标签。

## 范围内

- 抖音下载服务 adapter 解析并校验 `title`、`description`、`tags`。
- 内容提取记录保存来源标题、来源描述和来源标签。
- 内容提取详情和列表 API 返回来源标题、描述和标签。
- `DY爆款复刻` 自动创建出的生成任务下载 zip 时，写入 `meta.txt`。
- `meta.txt` 只包含标题、描述和标签三项来源元信息。
- 增加数据库迁移和后端测试。
- 更新产品规格和进度记录。

## 范围外

- 不改变抖音下载服务自身实现。
- 不把 `author_name` 或 `publish_timestamp` 写入当前下载包。
- 不改变普通任务创建和普通任务下载行为。
- 不新增前端编辑标题、描述或标签的能力。

## 完成标准

- 新下载的内容提取记录能持久保存来源标题、描述和标签。
- 通过内容提取关联的生成任务下载 zip 时包含 `meta.txt`。
- 普通非 DY 来源任务下载 zip 不额外写入 `meta.txt`。
- `./scripts/check.sh` 通过，或明确记录未通过原因。

## 风险 / 说明

- 现有历史内容提取记录没有来源元信息，下载包中会写入空字符串和空标签数组。
- 任务下载仍遵守本地资产打包规则，不从对象存储公开 CDN 回拉图片。
