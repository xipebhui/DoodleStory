# 图文故事商业化承接文档

这里保存 DoodleStory 图文故事内容实验从自用验证走向外部售卖时的承接资料。

当前第一版商业形态不是课程、不是纯工具订阅，也不是代运营，而是：

> 7 天图文故事起号实验陪跑。

## 文档索引

- `01-offer-definition.md`：第一版产品定义、目标客户、验证标准和不承诺边界。
- `02-sales-copy.md`：有人咨询时可直接发送的销售说明和短版话术。
- `03-customer-screening-form.md`：客户筛选表，用来判断对方是否适合进入 7 天实验。
- `04-seven-day-delivery-plan.md`：7 天中强度陪跑交付表。
- `05-pricing-and-boundaries.md`：首批定价、服务边界、升级路径和拒绝条件。

## 当前判断

- 先卖一次具体实验，不卖抽象方法论。
- 目标客户是已经在做抖音图文故事的个人、工作室或批量起号团队。
- 客户需要已经有号，最好至少 4 个，并能连续 7 天执行发布和数据反馈。
- 核心承诺是完成一轮受控内容实验并产出下一轮判断，不承诺播放量、涨粉、变现或起号成功。
- 自媒体第一阶段的作用是制造咨询入口和筛选目标用户，而不是证明成熟产品已经完成。

## 和内容实验的关系

`content-lab/experiments/` 记录自己的公域内容实验，目标是验证选题、生成、发布和复盘机制。

`content-lab/commercialization/` 记录对外售卖承接，目标是验证目标用户是否愿意为这套实验流程付费并持续使用。

两条线要分开判断：

- 内容验证成功：自己的 4 个号里，单条达到 1w 播放的概率超过 50%。
- 商业验证成功：目标用户付费参与 7 天实验，并真实按流程使用、反馈数据或愿意继续下一轮。
