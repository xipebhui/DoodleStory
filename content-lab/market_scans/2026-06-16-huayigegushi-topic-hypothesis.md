## 假设 H1：异常家庭规则怪谈

- hypothesis_id: `H1-family-rule-loop`
- topic_direction: 家庭关系异常循环
- story_archetype: family absurd loop / moral black comedy
- source_signal: `7649315939447871470` 家庭循环样本
- sample_account_signal: 爱奔跑的小兰，728 粉，26 作品，单条 57294 赞、14169 评论、73903 转发。

### 预测机制

如果故事把一个现实家庭关系设计成“看似伦理剧，实际像规则怪谈”的异常循环，观众会在评论区主动二创规则、吐槽主角命运和补充荒诞解释，从而拉高评论与转发。

### 用户需求

- 情绪释放：用荒诞感消化家庭伦理压力。
- 道德判断：观众会判断谁荒唐、谁可怜、谁像被命运惩罚。
- 参与感：评论区可以把故事改写成规则怪谈或段子。

### 推荐原创角度

不要复刻“年轻后妈/后后妈”的源故事。可改成新的家庭异常规则：

- 家里每多来一个亲戚，就会有人被迫搬走。
- 父母每次再婚，都把主角推到更尴尬的家庭身份里。
- 一个家庭永远只能留下两个“被承认的人”，第三个人会被关系系统排挤。

核心不是具体亲属身份，而是“现实关系被观众一眼看成规则”的结构。

### Hook / Payoff / Comment Trigger

- hook_type: 第一页给出强身份错位或关系不可能，例如“我爸带回来一个比我大不了几岁的家人”。
- payoff_type: 循环升级，不是单次反转；结尾让荒诞规则继续生效。
- comment_trigger: 观众能用一句话概括规则，例如“家里人数超过 X 就自动淘汰一个”。

### 风险边界

- 不写乱伦、未成年人性暗示、真实家庭爆料或可识别私人经历。
- 不用真实照片、真人姓名、地域标签作为可信度证据。
- 把荒诞点放在关系结构，不放在低俗伦理刺激。

### 预期指标

因为账号基线尚未确定，先设“最低继续线”和“爆点信号线”，在 `experiment_plan` 阶段按账号历史再校准。

| checkpoint | 最低继续线 | 爆点信号线 |
| --- | --- | --- |
| 2h | 出现至少 3 条非作者引导的规则化评论；点赞 >= 20；转发 >= 3 | 出现 1 条高赞苗头评论，内容能概括家庭规则；转发/点赞 >= 0.2 |
| 24h | 点赞 >= 120；评论 >= 10；转发 >= 20 | 评论里自然出现 2 个以上规则梗；转发 >= 80 |
| 72h | 点赞 >= 300；评论 >= 25；转发 >= 60 | 评论区形成稳定复读句式，转发 >= 点赞的 0.5 倍 |

### 下一轮验证句

如果 H1 发布后评论区自然生成“规则怪谈式解释”，且转发显著高于普通情感故事，则 `画一个故事` 的第一轮主攻方向应选择“现实家庭规则化”而不是纯爱治愈。

## 假设 H2：三回合家庭边界测试

- hypothesis_id: `H2-marriage-boundary-three-rounds`
- topic_direction: 婆媳/亲密关系边界
- story_archetype: marriage test / family boundary / action payoff
- source_signal: `7650413089900236066` 婆媳三回合样本
- sample_account_signal: 分镜里的小晴，549 粉，10 作品，单条 37188 赞、1629 评论、51013 转发。

### 预测机制

如果故事用三次非常具体的生活冲突测试一个男人是否能维护伴侣，且结尾用“他不吵架，但行动上把边界立住”兑现，观众会把自己的婚姻经验投射进评论区，形成高收藏、高转发和真实经历评论。

### 用户需求

- 身份投射：已婚女性、恋爱中女性和旁观者都能代入“他到底站谁”。
- 实用判断：观众会把故事当成伴侣筛选标准。
- 情绪补偿：现实里难以获得支持的人，会转发理想行动样板。

### 推荐原创角度

不要复刻旧床单、尿片、剩饭等具体桥段。可改成新的三回合：

- 回合一：母亲用“节约”侵犯新家庭边界。
- 回合二：亲戚用“为你好”要求女方让步。
- 回合三：丈夫不争吵，但通过退回物品、改规则、公开承担费用完成边界建立。

关键是每一回合都必须是生活细节，而不是抽象争吵。

### Hook / Payoff / Comment Trigger

- hook_type: 第一页给一个小但刺痛的家庭细节，例如“婆婆把别人不要的东西递给她，说这叫过日子”。
- payoff_type: 行动兑现，不靠嘴炮审判。
- comment_trigger: 评论区会写“我老公只会说她是我妈”“男人的态度决定婆家态度”等个人经历。

### 风险边界

- 不煽动性别对立，不把婆婆、丈夫或女性写成单一恶人。
- 不使用真实家庭投稿的可识别细节。
- 不做法律/心理咨询式建议，只呈现故事行动。

### 预期指标

| checkpoint | 最低继续线 | 爆点信号线 |
| --- | --- | --- |
| 2h | 出现至少 2 条“我老公/我婆婆/我家”代入评论；点赞 >= 20；收藏 >= 3 | 出现真实经历长评；收藏/点赞 >= 0.08 |
| 24h | 点赞 >= 100；评论 >= 8；转发 >= 20；收藏 >= 10 | 评论里出现伴侣/婆媳经验讨论，收藏 >= 30 |
| 72h | 点赞 >= 250；评论 >= 20；转发 >= 60；收藏 >= 25 | 转发 >= 点赞的 0.3 倍，评论区持续出现现实经历投射 |

### 下一轮验证句

如果 H2 发布后收藏和转发强于 H1，且评论集中在真实家庭经验而不是段子二创，则第一轮生成 brief 应优先做“三回合家庭边界”。

## 暂缓假设

### 纯爱治愈

`7651192895256480858` 的纯爱样本互动强，但账号成熟度高，且结尾真人合照提供强真实感。DoodleStory 第一轮不应直接依赖真人合照。后续可把它拆成“轻喜剧赌约 + 女主早已主动选择”的结构参考。

### 社会安全

`7651205691718698483` 的社会安全样本证明公共议题评论动员强，但涉及性侵、公共事件、二次伤害和平台敏感判断。本轮只保留“证据式结尾”和“评论声援机制”观察，不生成。

## 发布前仍需固定的变量

进入 `experiment_plan` 前必须固定：

1. 实验账号：至少 1 个，重要假设建议 2 个账号。
2. 画风：统一一种 DoodleStory 可生成风格，不能 H1/H2 同时换画风。
3. 页数：建议 8-12 页；H1 可短，H2 需要三回合，建议 10-12 页。
4. 发布时间窗口：同一批假设尽量固定发布时间段。
5. 是否先做 `full_story_extract`：只有用户批准某个种子样本进入生成 brief 时才执行。
