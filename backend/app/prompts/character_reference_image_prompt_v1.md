## 硬性规则

- 只生成这个人物的清晰角色参考图。
- 保持正面或三分之二角度。
- 完整呈现头发、脸部关键特征、服装、体态和标志物。
- 背景保持简单，不要抢占人物。
- 不要加入文字、标题、Logo、水印、对话框、复杂背景或其他主要人物。
